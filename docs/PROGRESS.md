## Текущее состояние

Этап 2 готов. Есть каркас Vite + React + TypeScript + Vitest, данные в `data/game-data.json`, загрузчик с проверкой и сайт со списком кораблей и всех 117 карт. Сайт публикуется на GitHub Pages через GitHub Actions после слияния в `main`.

- `scripts/convert-data.py` переносит `reference/data3.py` в `data/game-data.json` без потерь: те же имена полей и операций `fx`, кортежи — массивы, `tags` — отсортированный массив. Колода хранится как список уникальных карт с полем `copies`.
- `src/engine/types.ts` — типы данных; `src/engine/data.ts` — `loadGameData` (проверка, все ошибки сразу, с названием карты или корабля) и `deckCards` / `legendCards` / `seaCards` (по одной записи на копию, коды как в `data3.py`: `Ж-01`, `Ж-Л`, `С-01`).
- Параметры Залпа у каждого корабля: `volleyCost` 1, `diagDamage` `{ "offset": -1 }` (или `{ "fixed": n }`), `defaultTrack` `hull`, `volleysPerTurn` 1, `volleyModes` `[]`. Если поля нет, загрузчик подставляет значение версии 0.3.
- `tests/data.test.ts` — 25 тестов загрузчика.
- Следующий шаг — этап 3: движок, часть 1.

Этап 1: `RULES.md` — свод правил v0.3 по пунктам, подтверждённый пользователем, и `QUESTIONS.md` — 37 вопросов, все решены.

- Тексты, стоимости и число копий всех карт в `reference/data3.py` сверены скриптом с PDF — совпадают. Характеристики кораблей совпадают с планшетами.
- В `RULES.md`, раздел 21, — таблица расхождений `sim.py` со сводом. Она нужна на этапе 6, чтобы объяснить отличия статистики от PDF (с. 26).

## Решения, принятые по ходу

- Этап 1. Если `sim.py` однозначно решает вопрос по правилам и не противоречит тексту PDF, берём как в `sim.py` (в `RULES.md` — пометка «по sim.py»). Пользователя спрашиваем только там, где `sim.py` молчит или противоречит тексту.
- Этап 1. Правка v0.3 от автора: «Голландец» не может уходить под воду два своих хода подряд (`RULES.md` 14.8).
- Этап 1. Из вариантов PDF в приложении делаем «Первую партию» и «Быстрый бой»; «Своя колода» — на потом.
- Этап 1. В `docs/TZ.md` поправлен раздел «Интерфейс → Стол»: своя команда всегда снизу, столбцы не зеркалятся, подписи «Вы» и «Союзник».
- Этап 2. Шкалы в данных: `hull`, `sails`, `guns`, `crew` — в `data3.py` есть Заряды по Пушкам (`track: "guns"`).
- Этап 2. Список допустимых операций `fx` (`OPS`, `REACTIONS`, ключи `fx`, ключи моря) лежит в `src/engine/data.ts`. Новая операция в данных требует добавить её туда — иначе загрузчик выдаст ошибку.

## Идеи на потом

- Вариант «Своя колода» из PDF (с. 4): перед партией собрать колоду из 24 карт своей команды, не больше 2 одинаковых.
