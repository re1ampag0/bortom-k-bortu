## Текущее состояние

Этап 8 готов: игра по сети, каждый со своего устройства, через наш сервер. `npm run lan` на ноутбуке раздаёт сайт и игру по Wi-Fi и печатает адрес и QR-код для других устройств; для VPS — Docker (простой вариант `http://<IP>:8080` и вариант с доменом, Caddy и HTTPS). Инструкция для новичка — `DEPLOY.md`. Вторая очередь этапа 7 (красивый показ действий, баннеры, звук) по-прежнему впереди.

- **Движок для сети** (чистые функции, без изменений в правилах):
  - Настройка партии `pauseEmptyWindows`: окно Реакций открывается и тогда, когда Реакций ни у кого нет (`waiting: []`); новое действие `closeWindow` — «все, кто ещё решал, пропускают» (им же закрывает окно таймер комнаты). Без настройки движок, боты и `npm run sim` работают как раньше (Пираты 46,5 %).
  - `viewFor`: противник видит в окне Реакций всю защищающуюся команду «решающей» — не видно, у кого есть Реакция; `eventsFor` прячет от противника «без Реакции» и состав `windowOpened`. Верх колоды моря после «Тиа Дальмы» виден сыгравшему, пока эти карты не откроются (`sea.peek`); на столе — в окне карты моря.
  - Подсказки (`hints.ts`) работают на виде игрока: скрытые карты `'?'` не роняют сухой прогон; в 20 партиях ботов ответы на виде совпадают с ответами на полном состоянии.
- **Сервер** `server/` (Node 22 + `ws`, тот же `src/engine`):
  - `table.ts` — партия в комнате: вид `viewFor` для каждого игрока, журнал для каждой команды и зрителей (переданные, выбранные карты и Планы противника скрыты), «Ход окончен» каждого места, голоса «Сдаться», боты (командный — бот `sim.py`, на один корабль — `shipBot`), пауза пустого окна, таймер окна. Итоги для экрана конца партии считает сервер.
  - `permissions.ts` — кто какое действие может прислать (своё место; Заряд капитана в Залп союзника; «Сердце» — игрок «Индевора» или «Голландца»; Перестроение и «Тортуга» — любой человек команды; «Джек» — игрок «Жемчужины»); после «Ход окончен» — только ответы на решения до «Вернуться к ходу».
  - `rooms.ts` — комнаты: код из 5 символов без 0/O/1/I, токен места, места кораблей (можно сесть на оба корабля своей команды), зрители, «Посадить бота», жребий (меняет команды местами), тайная расстановка (любой человек команды), «Начать» (пустые места — боты), «Напомнить» (не чаще раза в 10 с), «Заменить ботом» (создатель; если он вышел — любой сидящий; вернувшийся забирает место).
  - `store.ts` — комната сохраняется после каждого изменения в `server-data/rooms/<код>.json` и восстанавливается после перезапуска; удаляется через 24 часа без действий.
  - `index.ts` — `/health`, `/lan` (адреса этого компьютера в сети — для ссылки и QR на localhost), сайт из `dist/` по `/bortom-k-bortu/` (с `/` — переадресация), WebSocket `/ws`, ограничение частоты (40 сразу, 20 в секунду) и размера (16 КБ) сообщений, проверка `ALLOWED_ORIGINS`, пинг соединений.
  - `main.ts` — запуск: `npm run lan` (сборка сайта и сервера, адреса, QR-код в консоли, понятная ошибка «порт занят»), `npm run server`, Docker. Сборка сервера — `npm run build:server` → `dist-server/main.js`.
- **Клиент:**
  - `src/net/ws.ts` — `NetClient` (соединение, токен в localStorage, переподключение 0,5 → 5 с и сразу при возвращении страницы — `visibilitychange`, `pageshow`, `online`; пинг каждые 5 с, «мёртвое» соединение без ответа 12 с закрывается и открывается заново) и `NetGame` с той же ролью для стола, что `LocalGame`.
  - `src/net/server-url.ts` — адрес сервера: с нашего сервера — тот же адрес; с github.io — `VITE_SERVER_URL` или поле «Адрес сервера». Страница по https и сервер `ws://` — понятная ошибка с адресом, который надо открыть.
  - Экран «По сети» (`src/ui/net/Lobby.tsx`): имя, «Создать комнату», «Войти по коду», ссылка `?room=ABCDE` открывает вход сразу; комната — код, ссылка с «Скопировать», крупный QR-код у создателя, места (кто сел, в сети ли), «Сесть / Встать», «Посадить / Убрать бота», «Жребий», варианты партии, «Союзники видят руки», «Разрешить подсказки», «Всё открыто», таймер окна (0 — нет), seed, «Начать»; тайная расстановка команды; на экране настройки — «По сети» и «Вернуться в комнату».
  - Стол по сети (`Game.tsx` + `NetParts.tsx`): своя команда снизу, без заставок и Undo; рука союзника — вкладкой для просмотра; на планшетах «Вы», имя союзника или «Бот»; Реакции и выборы — каждый за свой корабль; «Ход окончен · Отменить» 3 с → «Ждём союзника… · Вернуться к ходу»; у нападающего «Противник может ответить Реакцией…»; «Напомнить» вместо Undo, у ожидаемого — подсветка, «● Ваш ход» в заголовке и плашка «Вас ждут — напоминает …» (с вибрацией); «Заменить ботом» у пропавшего игрока; «Нет связи — переподключаемся…», через 10 с — «Сервер недоступен: проверьте, что ноутбук с игрой не уснул и вы в той же сети»; «Пока вас не было» после обновления страницы или потери связи; «Сдаться» — голос, команда сдаётся, когда нажали все её люди; «Подсказки» — личная настройка, если комната их разрешает; в конце — итоги и «Выйти из комнаты».
- **Бот на один корабль** (`src/engine/ai/shipBot.ts`): оценки и порядок хода бота `sim.py` (класс `TurnBot`, только экспортирован), но только для своего корабля (или как капитан утонувшего); ходит после «Ход окончен» человека-союзника; Перестроение не делает (решение команды за человеком); Реакции и выборы — за своё место. Командный бот не менялся; статистику по боту на один корабль не считаем.
- **Развёртывание:** `Dockerfile` (сборка + `node:22-alpine`, комнаты в `/data`, проверка `/health`), `docker-compose.yml` (простой, порт 8080), `docker-compose.https.yml` + `Caddyfile` (домен и HTTPS), `.env.example`; в GitHub Actions сайт собирается с `VITE_SERVER_URL` из переменной репозитория, проверки собирают и сервер. `DEPLOY.md` — Wi-Fi на Windows по шагам («Если не подключается»: частная сеть, брандмауэр, гостевой Wi-Fi → точка доступа с телефона, сон ноутбука, занятый порт, PowerShell), VPS простой и с доменом, обновление.
- **Тесты:** 431 в 27 файлах. Новые: `server` (14 — сервер и 2–4 клиента через `ws`: партии 2 на 2, 1 на 1 со зрителем и «человек + бот на корабль» доигрываются до конца, переподключение посреди партии, ни в одном сообщении нет чужой руки, Планов, порядка колод, чужих выборов и «без Реакции» противника; отказы чужих действий и после «Ход окончен», «Ход окончен» обоих союзников, «Сдаться» обоими, перезапуск сервера, «Заменить ботом» и возврат, «Напомнить», комнаты, ограничения частоты и размера, пауза пустого окна, без паузы против ботов, таймер окна), `ship-bot` (200 партий: бот играет только своим кораблём), `hints-view`, в `view` — окно Реакций и «Тиа Дальма». Playwright `e2e/net.spec.ts`: две вкладки (ноутбук и телефон) против локального сервера — комната, вход по коду, места, расстановка, Залп и Реакция, «Напомнить», конец хода, обновление страницы (игрок на месте), потеря сети и переподключение без перезагрузки, ход второго игрока; скриншоты — `docs/screenshots/stage8/`.

Этап 5: все 89 уникальных карт четырёх колод делают то, что написано на карте; список со статусом — раздел «Карты» ниже.

- **Розыгрыш карты** (`cards.ts`). Порядок: проверки → лимит Команды и «Кукла вуду» → стоимость → окно Реакций, если карта против вражеской команды (9.7, Q19) → эффект по операциям `fx.ops` → карта в сброс владельца, в руку укравшего («Ловкость рук») или из игры (Легенда). Легенды разыгрываются тем же кодом.
  - Пока карта разыгрывается, она лежит «на столе» (`state.card`). В тесте случайных партий она учитывается при подсчёте карт.
  - Часть карты, которую сделать нельзя, пропускается; карту, у которой ничего не выполнимо, сыграть нельзя (9.9, Q50).
  - «Кукла вуду» потопила корабль при розыгрыше — эффекта нет, карта в сброс владельца (шаг `cardPaid`, Q47); за Заряд — Залп отменяется целиком (шаг `volleyPaid`, Q51).
- **Выбор при розыгрыше** — поля действия `playCard`: `target` (вражеский корабль или игрок-противник), `ship` (свой или союзник), `repair` (как разделить клетки; без него — по порядку Пушки, Корпус, Команда, Паруса, как в `sim.py`), `souls`, `regroup`.
- **Выбор после того, как что-то открылось** — новое ожидание `pending: choice` и действие `choose`: «Компас Джека», «Безумный план», «Анжелика», «Шпион Мерсер», «Тиа Дальма», «Колокол» (каждый противник сам), «Кости лжеца» (оба втайне). `choiceFor(state, seat)` говорит, из чего и сколько выбирать.
- **Флаги:** у корабля `parley`, `voodoo`, `blockaded` (снимаются в конце хода его команды); у хода `volleyBonus`, `noDiag`, `marks`. «Чёрная метка» и «Поднять флаги!» — слагаемые Залпа, фиксируются при объявлении (18.1).
- **Дополнительный Залп от карты** («Зомби у пушек», «Всплытие»): без Пороха и Заряда, не в счёт Залпов хода; «Переговоры» его запрещают.
- **Названный корабль** (`namedShip`, Q43): «Уйти по ветру», «Зомби у пушек», «Сердце бьётся» и т. п. относятся к кораблю из названия, даже если карту играет союзник. Утонул — к кораблю капитана. Украденная карта с названием вражеского корабля — к тому, кто играет. Планы — только у «Жемчужины» на плаву (Q43а).

Новые операции — в `OPS` (`data.ts`). Операции бонуса «План:» добавляются к операциям карты (`planFx`).
- **Тесты:** 376 штук в 20 файлах. Новые: `cards-pearl`, `cards-revenge`, `cards-endeavour`, `cards-dutchman` — по файлу на колоду. `random-games` случайно заполняет параметры карт и отвечает на выбор.
  - Старые тесты, которые играли карты без эффекта, получили цель (`target`) или повреждённый корабль. Проверки не менялись, кроме одной: после «Сто лет службы» у «Голландца» на 1 Душу больше — карта теперь наносит урон по Команде (14.7).

## Решения, принятые по ходу

- Этап 1. Если `sim.py` однозначно решает вопрос по правилам и не противоречит тексту PDF, берём как в `sim.py` (в `RULES.md` — пометка «по sim.py»). Пользователя спрашиваем только там, где `sim.py` молчит или противоречит тексту.
- Этап 1. Правка v0.3 от автора: «Голландец» не может уходить под воду два своих хода подряд (`RULES.md` 14.8).
- Этап 1. Из вариантов PDF в приложении делаем «Первую партию» и «Быстрый бой»; «Своя колода» — на потом.
- Этап 1. В `docs/TZ.md` поправлен раздел «Интерфейс → Стол»: своя команда всегда снизу, столбцы не зеркалятся, подписи «Вы» и «Союзник».
- Этап 2. Шкалы в данных: `hull`, `sails`, `guns`, `crew` — в `data3.py` есть Заряды по Пушкам (`track: "guns"`).
- Этап 3. Генератор случайных чисел хранится в состоянии (`state.rng`), а не передаётся отдельным аргументом: так сохранение, загрузка и Undo работают без дополнительной логики. Партия по-прежнему воспроизводится по `seed` и списку действий.
- Этап 3. Числа правил, которых нет в `data3.py`, лежат в разделе `rules` файла `game-data.json`. Раздел `econ` не трогаем: он переносится из `data3.py` без потерь.
- Этап 3. Приказы и Ремонт до этапа 5 разыгрываются без эффекта: нужны для проверки лимита Команды.
- Этап 3. `diagDamage: { fixed: n }`: урон Залпа по диагонали считается от n вместо «Пушки − 1», остальные модификаторы прибавляются как обычно. Карта «штраф за диагональ не применяется» возвращает расчёт от Пушек.
- Этап 3. Души всегда платит «Голландец» своей команды, пока он на плаву (как в PDF, в `sim.py` иначе): «Сто лет службы» может сыграть любой корабль Компании. Если «Голландец» утонул или карту украл противник — сыграть нельзя. RULES 6.3, Q39, расхождение 21.15.
- Этап 4. Движок ждёт решений через очередь шагов в состоянии (`queue`, `pending`), а не через колбэки: так состояние остаётся JSON, сервер и Undo работают без доработок.
- Этап 4. «Джек ускользает» — решение Пиратов (`pending: jack`), а не автоматический побег, как в `sim.py`: на карте написано «Сыграйте». Боты этапа 6 будут играть его так же, как `sim.py`.
- Этап 4. Окно Реакций открывается только тем, у кого есть Реакция, которая сейчас что-то сделает. После каждой сыгранной Реакции окно предлагается заново (RULES 12.5).
- Этап 4. Q40–Q42 («Прикрыть бортом» и диагональ, «Залп с обоих бортов» при «Тумане» и против «Всё по плану») — ответы в `RULES.md` 18.1–18.3, 18.11.
- Этап 4. Одинокий корабль при побеге Джека, «Течении» и «Мальстрёме» переходит на пустое место, как в `sim.py` (RULES 16.0). «Зомби-офицеры» и «Морская пехота» против карты играет любой корабль команды, как написано на карте (RULES 21.18).
- Этап 4. В `createGame` добавлены `sea` и `legends`. Тесты этапа 3 играют без моря, чтобы карта моря не меняла их результат.
- Этап 2. Список допустимых операций `fx` (`OPS`, `REACTIONS`, ключи `fx`, ключи моря) лежит в `src/engine/data.ts`. Новая операция в данных требует добавить её туда — иначе загрузчик выдаст ошибку.

- Этап 5. Где `data3.py` упрощает карту, точный `fx` задаётся в `scripts/convert-data.py` (`FX_OVERRIDES`), а не правкой JSON вручную: `npm run convert-data` их не затирает.
- Этап 5. Выбор, известный до розыгрыша (цель, раздел клеток), передаётся в `playCard`; выбор после того, как карта что-то открыла, — через `pending: choice` и `choose`. Карты при выборе остаются в колодах и руках, состояние по-прежнему JSON.
- Этап 5. Ответы пользователя Q43–Q46 («названный корабль», Планы только у «Жемчужины», «Кукла вуду», кто выбирает игрока и карту, «Строй линии» по желанию) — в `RULES.md` 18.5, 18.6, 18.16, 18.18–18.20.

- Этап 6. Бот — генератор действий, а не функция «состояние → действие»: так порядок хода `AI.run` из `sim.py` переносится один в один. На этапе 7 тот же генератор будет ходить за бота в интерфейсе.
- Этап 6. Где у карты в приложении точный эффект (`FX_OVERRIDES`), бот оценивает её по `fx` из `data3.py`, как `sim.py` (`RULES.md` 21.24). Где в `sim.py` нет выбора (Компас, Безумный план, Анжелика и т. п.), бот выбирает по простым правилам из `RULES.md` 21.А.
- Этап 6. Ход, который заканчивается победой, засчитывается в статистику «за ход», как в `sim.py`. Первый Трюм Пиратов (+2) начисляется уже в `createGame` и тоже учитывается.

- Этап 7. Человек или бот — для команды целиком (бот из `sim.py` ходит за команду); бот-союзник человека — этап 8.
- Этап 7. Подсказки интерфейса (можно ли сыграть, урон Залпа, «4 → 2») — сухой прогон `applyAction` в `hints.ts`, а не своя копия правил в интерфейсе.
- Этап 7. Матч ботов — с открытыми руками; у зрителя снизу Пираты. Против ботов снизу команда человека, вдвоём — команда, за которой устройство.
- Этап 7. Undo — стек состояний в `LocalGame`; сбрасывается при доборе, перемешивании, море, просмотре карт, случайности, решении противника или бота и конце хода.

- Этап 8. Решения автора: таймеров нет (таймер окна Реакций в комнате по умолчанию 0); «Напомнить» и «Заменить ботом» вместо таймеров; бот на один корабль — отдельный от бота `sim.py`, без статистики; заставок по сети нет; «Подсказки» — личная настройка, в комнате «Разрешить подсказки».
- Этап 8. Ответы на вопросы плана: пауза «Противник может ответить…» 0,7–1,5 с — во всех окнах (до урона, после Залпа, карта против команды), только когда у защищающихся нет доступной Реакции, и только если в обеих командах есть люди; решения за команду (Тортуга, Перестроение, расстановка) — любой человек команды, засчитывается первый ответ; «Сдаться» — когда нажали все люди команды; один игрок может сесть на оба корабля своей команды.
- Этап 8. Пауза пустого окна сделана в движке (окно с `waiting: []` и действие `closeWindow`), а не задержкой на сервере: виды нападающих одинаковы в настоящем и в пустом окне, запись партии воспроизводится.
- Этап 8. Журнал строится на сервере отдельно для каждой команды и зрителей; клиент получает новые строки с номера, после переподключения — весь журнал.
- Этап 8. Сервер собирается Vite в один файл `dist-server/main.js` (движок и данные внутри); `ws` и `qrcode` — зависимости npm.
