Задача P6: капитан утонувшего корабля не стреляет Залпом союзника сам. Отвечай по-русски.

Жалоба автора: по сети, когда его корабль утонул, он мог нажать Заряд и «дать Залп» — то есть потратить
Залп и Порох союзника без его ведома.

Правило (не меняется): RULES 17.2–17.3, Q6, Q7. Капитан утонувшего корабля не выбывает, играет 1 карту
за ход за корабль союзника; свой Заряд может добавить к Залпу союзника (это его 1 карта за ход);
1 Реакция в ход противника. Баланс 46,5 % считается с этим.

Решение автора (утвердить перед запуском, вариант А):
- А. Залп начинает только игрок живого корабля. Заряд капитана — ПРЕДЛОЖЕНИЕ: капитан нажимает Заряд →
  «Предложить «Ядра» для Залпа «Мести»»; у союзника в панели Залпа появляется «Заряд капитана: Ядра (+1)»,
  он выбирает его или нет. Капитан видит «Предложено…» и может отозвать. На одном экране и против ботов
  (одна сторона — один человек) всё как сейчас, только с понятными подписями.
- (Б — НЕ делать без отдельного решения: полностью запретить карты капитана. Это изменение правил и баланса.)

Где: `server/permissions.ts` (`captainCharge` разрешает капитану весь Залп), `src/ui/game/Game.tsx`
(`startPlay` для Заряда: `shooter = seatShip(s, holder)` — у капитана это корабль союзника),
сетевые сообщения `src/net/ws.ts`, `server/table.ts`.

Сделай по шагам, коммит после каждого (ветка `p6-captain`). Сначала план (режим плана).
1. Тест сервера (сейчас падает): капитан по сети не может прислать `volley` от имени корабля союзника;
   союзник может прислать `volley` с `chargeFrom` = место капитана, если капитан предложил этот Заряд.
2. Сообщения «предложить / отозвать Заряд» (только между союзниками; противнику не уходят — расширь тест
   утечек). Предложение исчезает в конце хода и после Залпа.
3. Интерфейс: у капитана над рукой — «Вы капитан на борту «Мести»: 1 карта за ход за «Месть», Порох —
   команды»; Заряды подписаны «предложить в Залп «Мести»». У союзника — предложенный Заряд в панели
   Залпа. Планшет утонувшего корабля — без кнопок (уже так).
4. e2e по сети (две вкладки): капитан предлагает Заряд, союзник стреляет с ним; капитан не может
   начать Залп сам.
