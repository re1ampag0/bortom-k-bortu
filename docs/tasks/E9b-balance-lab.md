Задача E9b (этап 9, часть 2): лаборатория баланса на сайте. Отвечай по-русски.
ТЗ: `docs/TZ.md`, раздел «Лаборатория баланса», этап 9: «Сравнение двух пресетов на 1000 партиях
работает на сайте». Нужна E9a (пресеты). Правила не меняются, `npm run sim:check` = 46,5 %.

Сделай по шагам, коммит после каждого (ветка `e9b-lab`). Сначала план (режим плана).

1. Ядро без интерфейса: функция, которая для набора данных и настроек (число партий 100–5000, seed,
   вариант, кто ходит первым, отключённые особенности) возвращает сводку. Используй `runSims`/`summarize`
   из `src/engine/sim/sim.ts`, не пиши второй симулятор. Отключение особенностей — как `cfg.off`
   в `reference/sim.py`: `souls`, `jack`, `bottle`, `free_regroup`, `sword`, `plans`, `dive`, `heart`
   (по умолчанию ничего не отключено, `sim:check` не меняется).
   «Кто ходит первым»: если движок не умеет «Компания первой», добавь настройку партии (по умолчанию
   Пираты; стартовый Порох и доход первого хода относятся к первой и второй команде, как в ТЗ).
   Тест: с данными v0.3 и seed 1 на 3000 партий — те же 46,5 %, что CLI.
2. Web Worker(ы): партии идут в фоне, по `navigator.hardwareConcurrency − 1` воркеров, прогресс, «Отмена».
   Результат детерминирован: тот же seed и данные — те же числа при любом числе воркеров (тест).
3. Экран «Лаборатория» (ссылка со стартового экрана и из редактора): выбор A и B (основной или пресет),
   настройки, «Запустить». Результаты по каждому набору:
   - победы сторон с 95 % доверительным интервалом (Уилсон);
   - длина партии: среднее и 10–90 %;
   - Порох за ход по статьям (доход, Залпы, карты, Реакции, особенности, сгорело), доля ходов
     с пустым Трюмом;
   - розыгрыши каждой карты на копию: самые частые и «мёртвые»;
   - урон по источникам; использование Легенд и особенностей.
   A и B рядом; значимые различия (p < 0,05: для побед — z-тест двух долей, для средних — t-тест Уэлча)
   подсвечены. Числа с единицами, выровнены.
4. Кнопка «Сравнить «Пираты первыми» и «Компания первой»» — готовый запуск для решения автора
   (если разница ≤ 3 п. п., монета сможет решать и первый ход — это потом отдельной настройкой).
