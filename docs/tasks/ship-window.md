# ship-window

Основание: принятый пользователем план от 24.10.2026, ветка ship-window от main b59cd7d.
Эталон — docs/mockups/ship-window (Main, Endeavour, Revenge, Dutchman, Phone).
Только вид и отрисовка; данные и правила игры, движок и сервер не менять.

Этапы (по одному коммиту и push):
1. Каркас и тело: 920×640 по центру ноутбука; при недостатке места пропорциональный
   масштаб без обрезания. Табличка/медаль, девиз, реальные шкалы, особенности,
   карта Легенды, Рука/Колода/Сброс. Сброс открывает существующий DiscardSheet.
   Души: оформление обменов череп → значок трека, +1, как после ui-fixes.
2. Четыре живые сцены: заранее подготовленные изображения, decode до показа;
   только transform/opacity HTML, огонь 2–4 готовых кадра, мелочь холст/плитки.
   Пауза при закрытии, скрытой вкладке, вне экрана и во время клипа.
3. Телефон: полноэкранный прокручиваемый лист по Phone, без mix-blend,
   половина частиц. Кадры всех четырёх кораблей на 430×740.
4. Щупальца из макета: TENT, арт карты Кракен, подготовленные наклейки анимации.

После этапа только typecheck, коммит/push и короткий отчёт с кадрами.
В конце — только новые/задетые адресные e2e один раз, perf-guard один раз,
полный npm test один раз. Полный e2e, sim, build:server не запускать.
Кадры рядом с макетом: все четыре корабля, 1366×660, 1920×944, 430×740.
Замер 390×844/DPR3/CPU×4: 10с открытого и закрытого окна, Layout/Paint,
крупных слоёв ≤3; закрыто Paint0. Game0 и SVG на весь стол0 при открытом окне.
