Задача E9a (этап 9, часть 1): редактор данных — «админка» без Claude. Отвечай по-русски.
ТЗ: `docs/TZ.md`, раздел «Редактор данных»; решения автора — ниже. Правила и движок не меняются.

Решения автора:
- Редактор правит числа, тексты, стоимости, число копий и включение карт моря. Новые механики
  (новые операции `fx`) — только через Claude: имена операций в редакторе не редактируются.
- Правки живут в личных пресетах в браузере (localStorage), без пароля. Пароль в коде сайта не делать:
  его видно всем.
- «Сделать основным» = кнопка «Скачать как основной» (готовый `data/game-data.json`) + инструкция,
  как загрузить его в репозиторий через GitHub (Upload files / карандаш «Edit»). Сайт пересоберётся сам.
- Если поменяли числа в `fx`, а текст карты — нет: предупреждение «текст карты мог устареть».

Сделай по шагам, коммит после каждого (ветка `e9a-editor`). Сначала план (режим плана).

1. Развести данные сайта и данные тестов. Сейчас `tests/helpers.ts` берёт `data/game-data.json`,
   поэтому любая правка баланса ломает тесты и выкладку. Сделай замороженную копию
   `tests/fixtures/game-data.v0.3.json`; все тесты правил и `npm run sim:check` (46,5 %) работают на ней.
   Для `data/game-data.json` оставь проверки «данные проходят загрузчик» и «100 партий ботов без исключений».
   После этого шага все проверки зелёные, а правка чисел в `data/game-data.json` их не ломает
   (проверь: временно измени стоимость одной карты, прогони, верни).
2. Экран «Редактор данных» (ссылка со стартового экрана и `?editor`), вкладки:
   Корабли (шкалы, Души, стоимость Залпа, урон по диагонали), Экономика (доход, первый доход, Трюм,
   стартовый Порох второй команды), Карты (по колодам: стоимость, Души, копии, ценность `v`, числа
   внутри `fx` — поля генерируются по структуре `fx`, имена операций только для чтения; тексты `big`,
   `text`, `flavor`), Море (включено/выключено, тексты). Для таблицы карт — поиск и фильтр по колоде/типу.
3. Колонки «ценность / норма / перевес» по формуле PDF, с. 25: норма Заряда 1, Реакции 1,5, Приказа
   и Ремонта 2; +1 за каждый Порох или Душу в стоимости; +2 у Легенды. Перевес подсвечен
   (зелёный ≤ −0,5, красный ≥ +0,5).
4. Пресеты: создать (копия основного или другого пресета), переименовать, удалить; изменённые ячейки
   подсвечены, счётчик «изменено N»; «Вернуть как в основном» для ячейки и для всего пресета;
   экспорт/импорт JSON. Каждый пресет проходит тот же загрузчик данных; ошибки — по-русски,
   с путём («Карты → Месть → Ядра → стоимость: должно быть целое ≥ 0»).
5. Играть с пресетом: на экране подготовки в «Дополнительно» — выбор пресета (только игры на одном
   экране и против ботов; по сети — задача E9c). Запись партии хранит данные пресета, чтобы
   «Загрузить партию» воспроизводила её точно.
6. «Скачать как основной»: перед скачиванием — проверка загрузчиком и 100 партий ботов в Web Worker
   без исключений (прогресс, отмена). Затем файл и окно-инструкция по шагам: открыть репозиторий →
   `data` → `game-data.json` → «Upload files»/«Edit» → «Commit» → дождаться зелёной галочки → сайт
   обновится через несколько минут.

Не делай: пароля и серверной части (это E9c); лаборатории баланса (E9b).
