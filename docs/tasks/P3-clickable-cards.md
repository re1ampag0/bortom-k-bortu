Задача P3: карты в журнале и карты моря при выборе нажимаются и открываются целиком. Отвечай по-русски.

Решения автора:
- Названия карт в журнале — ссылки: нажатие открывает карточку карты (как из руки).
  Карты моря в журнале — тоже, открывается карта моря.
- «Тиа Дальма»: три карты моря — не кнопки с названием, а мини-карты моря (картинка, название, эффект),
  у каждой кнопка «i» — карта целиком. Нажатие по самой карте ставит порядок 1-2-3, как сейчас.
- Строка «Следующие карты моря («Тиа Дальма»…)» в окне моря — названия тоже ссылки.
Как это выглядит — сцена «Тиа Дальма: карты моря» и журнал справа в
`docs/mockups/anim/level1/anim-demo.html` (сцена `tia`; кадры — `capture.mjs`, см. README в той папке).

Где сейчас: строки журнала — `LogLine` в `src/engine/log.ts` (только текст), вывод — `LogList`
в `src/ui/game/Overlays.tsx`; выбор «Тиа Дальмы» — `ChoicePanel` в `src/ui/game/Panels.tsx`
(для `tia` — кнопки `choice` с названием); карточка карты — `CardDetail`, окно моря — `SeaSheet`
(показывает только текущую карту).

Сделай по шагам, коммит после каждого (ветка `p3-cards`):
1. `LogLine` получает поле `cards: string[]` — коды карт, упомянутых в строке, в порядке появления,
   и `sea?: string` — код карты моря. Только видимые этому игроку карты: скрытые (`'?'`) не попадают.
   Тест в `tests/view.test.ts`: в журнале противника нет кодов карт, которых он не видит
   (чужие Планы, переданные карты).
2. `LogList`: в тексте строки находи «Название» каждой карты из `cards` (точным поиском строки, а не
   регулярным выражением — у карт бывают вложенные кавычки, например «Колокол «Голландца»») и делай
   его кнопкой-ссылкой; нажатие открывает `CardDetail`. Для `sea` — окно карты моря.
   То же в листе «Весь журнал».
3. `SeaSheet` умеет показать любую карту моря по коду (не только текущую).
4. `ChoicePanel` для `tia`: мини-карты моря с «i», как в эталоне. Ссылки в строке
   «Следующие карты моря».
5. e2e (Playwright): нажатие на название карты в журнале открывает её карточку; «i» у карты моря
   в выборе «Тиа Дальмы» открывает карту моря. Новые библиотеки не добавляй.

Не делай: не меняй тексты строк журнала и файл «Скачать партию» (формат записи тот же).
