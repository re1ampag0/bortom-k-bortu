Задача E9c (этап 9, часть 3): пресеты на сервере и пароль администратора. Отвечай по-русски.
Нужны E9a и E9b. Правила не меняются, `npm run sim:check` = 46,5 %.

Решения автора: пароль администратора — только в `.env` сервера (`ADMIN_PASSWORD`), никогда в коде сайта.
Создатель комнаты выбирает пресет. ВАЖНО: настоящий пароль пользователь впишет сам; не придумывай его
и не проси прислать.

Сделай по шагам, коммит после каждого (ветка `e9c-admin`). Сначала план (режим плана).

1. Сервер (`server/`): папка `server-data/presets/`; `GET /presets` (имена, хэш, дата),
   `GET /presets/:name` (данные), `POST /admin/presets` и `DELETE /admin/presets/:name` с заголовком
   `Authorization: Bearer <пароль>`. Нет `ADMIN_PASSWORD` — admin-маршруты выключены (403 с понятным
   текстом). Пресет проходит тот же загрузчик данных; лимит размера; ограничение частоты как у ws;
   неверный пароль — 401 и задержка.
2. Комнаты: при создании — выбор пресета (по умолчанию «Основной»); пресет хранится в комнате
   и в `server-data/rooms/<код>.json`; партия на сервере идёт на его данных; клиенты получают
   хэш и загружают данные пресета (`GET /presets/:name`, кэш по хэшу) до показа стола.
   Название пресета видно в лобби и в заголовке партии.
3. Редактор (E9a): кнопка «Загрузить на сервер» — спрашивает адрес сервера и пароль (пароль хранится
   только в `sessionStorage`), показывает ответ сервера. Список пресетов сервера с «Удалить».
4. `DEPLOY.md`: как задать `ADMIN_PASSWORD` для `npm run lan` на Windows (файл `.env`, по шагам)
   и в Docker (`.env` рядом с compose).
