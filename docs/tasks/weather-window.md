# weather-window

Принят план: пять этапов (каркас/данные →5сцен →6сцен →6сцен →телефон).
Основание main8d6f922, PR75. Использовать общий механизм ship-window.
Сцены920×210, окно920×600; телефон по Phone.
Эффекты/строки реальные, чужую скрытую информацию не восстанавливать.
Поправки пользователя: реплики с демонстрационными числами переформулировать
или подставить настоящее; при отсутствии достоверного старого значения —
только текущее, например «Трюм5». Список замен в отчёте этапа1.
После этапа typecheck, commit/push; npm test один раз в конце, адресные e2e
только новые/задетые, perf-guard. Полный e2e/sim/build:server запрещены.
Кадры:6 указанных погод на1366×660/430×932. Замер390×844,DPR3,CPU4,
10с открыто/закрыто, Layout/Paint, крупные слои≤3, Game0, SVG0.
