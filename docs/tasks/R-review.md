Задача R: независимая проверка PR перед слиянием. Отвечай по-русски.

Запускается в НОВОЙ сессии (`/clear`) или субагентом, который не писал этот код. Номер PR и файл задачи
назовёт пользователь.

1. Прочитай файл задачи и `docs/mockups/anim/level1/PORTING.md` (если задача про анимации).
2. `gh pr view <N> --json files,body` и `gh pr diff <N>`. Прочитай изменённые файлы целиком.
3. Пройди по «Готово, когда» задачи: каждое требование — выполнено? где доказательство? Запусти сам
   `npm run typecheck`, `npm test`, `npm run sim:check`; для анимаций — `node docs/mockups/anim/level1/
   validate.cjs` на свежем дампе и посмотри скриншоты парами с эталоном.
4. Ищи: изменение правил или баланса; утечку скрытого (новые поля событий через `eventsFor`); слой
   эффектов, ловящий нажатия; анимации, которые двигают не `transform`/`opacity`; выбор анимации по
   названию карты; удалённые или ослабленные тесты; «готово» без вывода команды.
5. Ответ — таблица «требование → выполнено / нет / не проверить → чем подтверждено» и список проблем по
   важности. Код не меняй. Merge — только если CI зелёный и проблем первого уровня нет.
