# Как смотреть доски

Доски — `artboards/*.dc.html` (формат холста Claude; стили и значения — в разметке и `<helmet>`).
Картинки лежат в `assets/` и подключены относительными путями. Чтобы открыть доску в браузере, запустите
в папке `weather-window/` (не в `artboards/`, иначе `../assets/` не найдутся) простой сервер (`python3 -m http.server`) и откройте `http://127.0.0.1:8000/artboards/Main.dc.html`
(по file:// браузер блокирует скрипты). `support.js` и `vendor/` нужны только для просмотра, в игру не переносить.
Устройство окна, логика и «что чем делать» — `NOTES.md`.
