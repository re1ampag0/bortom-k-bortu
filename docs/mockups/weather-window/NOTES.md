## Устройство окна (ноутбук 920×600, по центру; телефон — полноэкранный лист)
1. **Сцена 920×210** — живая картина погоды; слева латунная табличка «Море · весь раунд/сразу», имя карты, красная
   лента эффекта (поле `big`); справа кнопка ×.
2. **Тело** (фон — штурманская карта, неподвижный слой): «Что делает» + ярлыки состояния справа; текст карты;
   «Сейчас на столе» (весь раунд) или «Что изменилось» (сразу); строки по кораблям (сетка 2×2: верх — Пираты, низ —
   Компания) или по командам (одна строка на команду: Трюм, Перестроение, обмен местами); реплика Боцмана; строка из
   описания (flavor); история моря по раундам (кружки со значками art/wx.ts, текущий подсвечен); счётчик колоды/сброса.
3. **Карта моря справа 236×352** в игровом стиле: медальон со значком из art/wx.ts, имя, лента, текст, полоска
   «Раунд N».

### Логика строк («Сейчас на столе» / «Что изменилось»)
- Считать из настоящего состояния; формат «Параметр было → стало». Новое значение — зелёным, если стало лучше
  (`up`), красным, если хуже (`down`); `info` — нейтрально; `none` — строка приглушена курсивом («не задело»,
  «мимо», «уже полная»).
- Командный эффект (Трюм, Перестроение, обмен местами) — одна строка на команду (бейдж команды + ««Жемчужина» и
  «Месть»»), не дублировать по кораблям.
- Ярлыки: «до конца раунда N» (весь раунд) / «сработала в начале раунда N» (сразу); дополнительно «ход Пиратов» у
  Девятого вала и Мальстрёма (важно, чей ход), «ждёт решения команд» у Тортуги.
- Счётчик: «В колоде моря {17−N}» и «в сбросе {N−1}, на столе 1» для «весь раунд»; «в сбросе {N}» для «сразу».

## Что чем делать в игре (по docs/mockups/anim/RULES.md)
Общее: всё готовится при открытии окна; бесконечные анимации на паузе, когда окно закрыто/вкладка скрыта; движение
только transform/opacity у HTML-обёрток; на телефоне частиц вдвое меньше, без mix-blend.
- **Море** (ряды гребешков, пенная кромка) — те же слои, что на столе (ws-r0…r7, ws-edge): полосы со сдвигом
  translateX по периоду. В «Попутном ветре» — те же ряды, но быстрее (класс-модификатор сцены).
- **Облака** — наклейка-полоса шириной 2×920 (облака повторяются), translateX(−920px) linear, свои скорости слоёв.
- **Корабли** — наклейки bigships (assets/ship_*.svg) в обёртке: качка `w-calm` / `w-bob` (rotate+translateY вокруг
  ватерлинии 50% 91%). «Попутный ветер»: обёртка пересекает сцену translateX(0 → −1300px) за 8 с linear по кругу;
  бурун, след и вымпел — дочерние слои той же обёртки.
- **Солнце** — неподвижная наклейка (диск + свечение) + отдельный слой лучей rotate 120 с + слой «звёздных» бликов
  opacity/scale (дыхание 5 с). Без контура.
- **Дождь** — 3 слоя-плитки штрихов (морось / штрихи / длинные), каждый — картинка с копией сверху, translate по
  диагонали на высоту сцены, linear 1,05 / 0,62 / 0,36 с; коронки и кольца на воде — холст частиц или маленькие
  элементы opacity/scale; дальние завесы — полоса с градиентом translateX 70 с; дымка — неподвижный градиент.
- **Вспышки, молнии, зарницы** — готовые слои opacity (молния — заранее нарисованная рваная ветвистая линия со
  свечением, двойная вспышка).
- **Огонь** (Гроза, Ясное небо, костры) — 3 кадра пламени сменой opacity или scale/skew маленьких элементов; искры и
  угли — холст частиц.
- **Дым** — заранее размытые клубы (картинки), translate/scale/opacity.
- **Сырой порох, волна**: стена воды — наклейка в обёртке с overflow:hidden по уровню моря (растёт ИЗ моря),
  translateY по сглаженной кривой (кадры каждые ~2%, linear); гребень-перелив — отдельная наклейка поверх палубы,
  появляется на подъёме и стекает вниз; брызги/пыль/пена — отдельные маленькие слои; струи из шпигатов — неподвижные
  полупрозрачные формы + бегущие блики внутри (translateY в обрезке); всё в цикле 8 с.
- **Ясное небо, перестрелка**: вспышка из порта (наклейка, scale/opacity), ядро — смазанный штрих translate по дуге,
  попадание — вспышка + щепки (частицы), отдача — translate/rotate обёртки корабля, плашка «−N Корпус» — HTML,
  translateY/scale/opacity. Пробоины и дыры в парусах — неподвижные наклейки поверх корабля.
- **Течение** — две полосы струй translateX в разные стороны; корабли — обёртки translateX туда-обратно.
- **Мальстрём** — диск воронки, сжатый scaleY(.15) обёрткой, внутри вращается rotate (две скорости: край и горло).
- **Фон тела (штурманская карта)** — один неподвижный SVG/PNG, генерируется один раз.

## Генератор (generator/)
Python-скрипты, которыми собраны доски: common.py (шаблон, фон-карта, тело, карта моря), helpers.py (солнце, облака,
бочки, скалы…), scenes2…scenes6.py (сцены по картам, каждый следующий файл переопределяет часть сцен), build6.py
(сборка). Пути внутри — под окружение прошлого чата (/home/claude/…, /mnt/user-data/…); templates-v1/ — исходные
доски Бури/Тумана/Тортуги/телефона, из которых берутся шапка, море и кнопка. Использовать как справочник по
координатам и таймингам, не как готовый инструмент.
