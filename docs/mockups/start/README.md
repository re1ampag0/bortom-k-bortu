# Стартовый экран — светлый, «старая морская карта»

- start-laptop.png (1366×660) и start-iphone.png (430×740) — макеты.
- start.html — исходник макета (вёрстка, цвета, размеры). Шрифты в нём подключены из локальной папки fonts/, которой здесь нет; в проекте шрифты подключаются пакетами @fontsource/alegreya и @fontsource/alegreya-sans (кириллица и латиница).
- start-map.svg — готовая картинка морской карты (роза ветров, острова, курс эскадр). Нарисована с нуля, можно использовать как есть: положить в public/art/start-map.svg. Тексты внутри — шрифтом Alegreya.

Цвета: бумага #F1E8D4, вторая бумага #E8DCC2, чернила #2A2521, приглушённые чернила #6B6157, румбы #C9B48C, морская синь #24465C (плашка «Продолжить»), латунь #A8812E, сургуч #9E2B25.
Шрифты: Alegreya 800/700/500 — заголовки и названия режимов; Alegreya Sans 400/500/700 — остальной текст.
