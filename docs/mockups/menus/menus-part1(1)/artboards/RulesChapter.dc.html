8Залп

Залп: главный способ топить врагов. Каждый корабль даёт один Залп за ход.

  1. Потратьте 1 Порох.
  2. Выберите цель: вражеский корабль напротив или по диагонали.
  3. Если хотите, добавьте 1 Заряд. Он считается в лимит Команды, и его стоимость тоже надо заплатить.
  4. Противник может ответить Реакциями.
  5. Нанесите урон. Без Заряда Залп бьёт по Корпусу.

Сколько урона. Урон равен Пушкам стреляющего корабля. Дальше его меняют:

  • по диагонали урон на 1 меньше;
  • совместный залп: если второй корабль команды в этот ход стреляет в ту же цель, его Залп наносит на 1 урон больше; этот бонус бывает один раз за ход;
  • Заряды, Реакции и карта моря меняют урон так, как написано на них.

Урон не бывает меньше 0.

Боцман: «Стрелять наискосок можно. Попадать тоже. Просто слабее».

Пример

У «Мести» 3 Пушки. Залп по кораблю напротив нанесёт 3 урона, по диагонали 2. Если «Жемчужина» уже стреляла в ту же цель в этот ход, добавьте ещё 1.
