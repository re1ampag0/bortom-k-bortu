# Меню и экраны вне стола — макеты

Утверждённые пользователем макеты 24.10.2026. Это всё, что игрок видит вне стола:

- стартовый экран;
- подготовка партии;
- тайная расстановка и шторка «Передайте устройство»;
- игра по сети;
- Настройки и Правила.

## Как смотреть доски

Доски — `artboards/*.dc.html`. Это формат холста Claude: стили и значения записаны прямо в разметке и в `<helmet>`.

1. Запустите сервер **в этой папке** (`docs/mockups/menus/`), а не в `artboards/`, иначе пути `../assets/` не найдутся: `python3 -m http.server 8000`.
2. Откройте `http://127.0.0.1:8000/artboards/Main.dc.html`.

По адресу `file://` браузер блокирует скрипты, поэтому нужен сервер. `support.js` и `vendor/` нужны только для просмотра — в игру их не переносить.

## Что где

| Папка или файл | Что в ней |
|---|---|
| `artboards/` | 17 досок: ноутбук 1366×660 и телефон 390×844. `canvas.json` — их расположение на холсте |
| `assets/` | 4 корабля **без нарисованной воды** (см. NOTES.md, «Корабли и вода»), 4 значка шкал |
| `assets/icons/` | 13 детальных иконок |
| `rules-player.md` | Полный текст «Правила для новичка» — его показывает окно «Правила» |
| `generator/` | Справочник: как собраны море, форт, иконки, посадка кораблей, анимации, доски правил. В игру не переносить как есть |
| `previews/` | Обзор всех экранов картинками |
| `NOTES.md` | Устройство каждого экрана, что откуда берётся, как делать анимацию и что запрещено |
