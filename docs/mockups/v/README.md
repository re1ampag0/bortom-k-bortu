# Внешний вид V — «настольная игра + живое море»

Эталон для задач V1–V7 и U2 (`ПРОМПТЫ-V-внешний-вид.txt` у советника). Выбранный итог — **вариант 2 с элементами 1-го**:
стол из досок, лампа, предметы по краям; поле — печатная морская карта с живыми чернильными волнами и погодой;
картонные планшеты с силуэтом корабля, щитом Корпуса и кубиками, подписи шкал цветом; «Последнее» — на картуше;
рука веером в латунной рамке, тёплый свет у играбельных карт; «Ход окончен» — бордовая табличка.

- `stol-posle.html` — все артборды демо одной страницей (открывается в браузере без интернета).
- `gif/` — анимированные кадры: `9-итог-телефон`, `10-итог-ноутбук` (итог), `7/8-настольная-*` (вариант 2),
  `2-тревога-реакции` (U2), `6-залп` (V5), `3-стартовый-экран`, `4-победа` (V7).
  Шрифт в гифках запасной; в игре — Alegreya / Alegreya Sans.
- `src/*.dc.html`, `canvas.json` — исходники артбордов (разметка и CSS для переноса). Сами по себе не открываются:
  им нужен `support.js` холста. Главные: `Mix.dc.html` (телефон), `MixLaptop.dc.html` (ноутбук), `Start`, `Reaction`,
  `Volley`, `Victory`.

Вариант 1 («яркое море», щит и значки вместо шкал) отклонён как слишком «мобильный»: из него берём только живую воду
поля, щит Корпуса и рубашки карт веером.

Правила переноса: пиксель в пиксель не копировать; размеры и места — из настоящих планшетов (ноутбук 1366×660,
iPhone 430×740); только своя графика SVG/CSS, без кадров из фильмов; контракт `data-fx-*` анимаций не ломать.
