# Макеты 26.10.2026 (утверждены владельцем)

- `index.html` — галерея: каждый пункт «сейчас | будет» с подписью. Открыть в браузере.
- `img/` — кадры, снятые с настоящей игры (main 3b68988) с наложенными правками. На них ссылаются задания
  game-phone-fix, menus-speed, ui-polish, card-art (`img/<файл>`).
- `card-art/` — 81 картинка карт (WebP 600×360, рамка цвета типа уже внутри) и `manifest.json`
  (имя карты → файл, тип, колоды). `reference/card.css` — вид полной карты (.cc) и мини-карты (.cm),
  `reference/hand.css` — как мини-карта стоит в руке.

Правило для всех элементов: текст по центру, элементы не касаются друг друга.
