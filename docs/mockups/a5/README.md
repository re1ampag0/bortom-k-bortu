# Внешний вид A5 — эталон для переноса

Выбранный вид (октябрь 2026). Заменяет «Mix» из `docs/mockups/v/` — тот вид устарел, его не переносить.
Задачи переноса — у советника (V1a, V1b, FX, V2, V1c, U2, V5, V7, V-телефон); номер задачи называет пользователь.

Шрифты на образцах — с Google Fonts; в игре — пакеты `@fontsource` (Alegreya, Alegreya SC, Alegreya Sans, Old Standard TT).

## Решения пользователя (не менять без него)

- **Палитра:** светлый дуб стола, бумажные планшеты, латунь, бордо. Море между планшетами — нарисованное, спокойное
  (медленно плывущие гребни). Переключатель моря — позже в ⚙, на столе его нет.
- **Шкалы:** подпись + значки + число «9/11». Корпус — доски (потерянная — сломанная доска с трещиной), Паруса —
  парус, Пушки — пушка на лафете, Команда — матрос (потерянный — череп). Корпус — первая строка во всю ширину,
  Паруса / Пушки / Команда — вторая строка. **Эмблемы (щита) Корпуса нет.**
- **Шапка планшета:** рисунок корабля на светлом поле, имя (Alegreya SC), капитан курсивом; справа — веер из трёх
  рубашек с числом карт в руке и латунный медальон Легенды со своим знаком: «Джек ускользает» — компас,
  «Корабль в бутылке» — корабль в бутылке, «Кракен» — щупальце, «Армада Компании» — якорь.
- **Души** — зеленоватый череп со светящимися глазницами и «Души 1/5».
- **Погода** — неподвижная иконка в плашке «Море · весь раунд» справа сверху (без анимации внутри плашки).
- **Кнопки справа сверху:** книга — «Правила», шестерёнка — «Настройки».
- **«✓ готов»** — зелёная плашка в шапке планшета игрока, уже нажавшего «Ход окончен».
- **Цель Залпа** — красная восковая печать с пушкой («Под огнём») в шапке цели и красная рамка. Кольцо прицела
  (`.reticle`) убрать.
- **Справа внизу:** в свой ход — только «Отменить последнее действие» (круглая латунная кнопка); «Быстрее»,
  «До конца хода», «Пауза» — только пока ходит бот. «Ход окончен» — бордовая табличка; под ней строка
  «‹Союзник› готов — ход закончится, когда нажмёте вы».
- **Перестроение** — одна кнопка на команду, под Трюмом, с ценой («бесплатно», пока у Пиратов на плаву «Жемчужина»).
- **Карты в руке:** названия — Old Standard TT, с заглавной, без капители; цветная полоса типа; карты, которые
  сейчас не сыграть, — приглушены (серые).

## Решения пользователя после живого прототипа (18.10.2026)

- **Фон стола «Вещи на столе»:** тёмное дерево, по краям в тени мелкие предметы (штурвал, карта, циркуль), компас
  справа внизу (приглушён, ≈ 82 % непрозрачности), песочные часы за Трюмом пиратов.
- **Рамка моря — латунь.** В ⚙ позже — выбор рамки: латунь / дерево.
- **Трюм Компании** — в верхней строке слева, подпись «Трюм Компании · 5 из 8». Трюм пиратов — как в A5 (антуражный).
- **Плашка «Пираты · раунд II»** — текст по центру латунной плашки.
- **Текст карт** — Old Standard TT.
- **Статусы** — пока «ярлыки у Корпуса» (вариант со значками не отброшен окончательно).
- **«Голландец» под водой** — вариант «Толща воды».
- **Справа внизу** — ряд «Быстрее · До конца · Пауза · Отменить» (первые три — пока идёт показ/ходит бот).
- **Журнал** — понятные строки, названия карт выделены.
- **Анимации** — насыщенные; часть эффектов остаётся на поле (водоворот, дым, трещины, обломки, бутылка), но у
  каждого следа есть срок жизни (см. `fx/ANIMATIONS.md`, «Следы»), чтобы стол не превращался в кашу.
- **Легенды** начинаются с большой карты Легенды в центре (выход) и дальше — свой большой эффект.

## Рука (задача V2) — поведение

Образец статичный, поведение — словами:

- **Ноутбук:** веер с лёгким наклоном. Наведение — карта выпрямляется, поднимается и увеличивается (≈ ×1,12),
  соседи чуть расходятся; 150–200 мс. Играбельные — тёплое свечение. Нажатие — как сейчас (открыть / выбрать).
- **Телефон:** веер листается пальцем (инерция, прилипание к карте), карты у краёв затухают и наклонены сильнее,
  карта в центре — прямая. Касание — карта поднимается над рукой и увеличивается (≈ ×1,15), не закрывая
  «Ход окончен»; второе касание — как сейчас.
- `prefers-reduced-motion` и «простые спецэффекты» — без движения, только рамка выбранной.

## Чего в образце нет (дорисует советник; до этого — «по смыслу», в том же стиле)

Кнопки особых свойств («Сердце», «Погружение», «Душа → Корпус», «Казна»); окна; телефон. Трюм Компании, Пожары,
статусы, погружение и гибель — уже есть в `fx/prototype.html`.

## Правила переноса

- Только интерфейс: правила, движок, данные, боты, сервер не меняются. Числа и тексты — из `data/game-data.json`.
- Контракт анимаций `data-fx-*` сохраняется (см. `docs/mockups/anim/level1/PORTING.md`, раздел 3). Шкала
  значками — тот же `.cells` с детьми `<i>` и классом `on`, `data-fx-track` на строке шкалы, `data-fx-value` на числе:
  тогда `fxPoint` и `setTrack` работают без изменений.
- Только своя графика SVG/CSS, без эмодзи и кадров из фильмов. Корабли — свои обобщённые типы из `art/ships2.json`.
- Цвета — CSS-переменные в `:root` (`game.css`).
