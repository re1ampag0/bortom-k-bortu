# Перенос A5, часть 2 — что осталось (19.10.2026)

Продолжение `TASKS.md` (разделы 0, V1a–V1c, V2, FX-A–FX-D уже сделаны: PR #40, #41, #42).
Раздел «Как переносить из прототипа» из `TASKS.md` действует и здесь. Общие правила:

- Меняется только вид. Правила, движок (`src/engine`), данные, боты, сервер, протокол — не меняются. Логика анимаций
  (`planFx.ts`, `queue.ts`, `display.ts`, события) не меняется, кроме мест, где раздел говорит об этом прямо.
- Контракт `data-fx-*` и существующие `data-testid` сохраняются. Новые элементы — со своими `data-testid`.
- Своя графика SVG/CSS, без эмодзи. Цвета — CSS-переменные в `:root` (`game.css`).
- Числа и тексты карт — из `data/game-data.json`. Если для вида нужно число, которого нет в состоянии игры или в
  журнале, — не добавлять его в движок, а посчитать в интерфейсе из того, что уже приходит; если и так нельзя —
  пропустить и написать об этом в описании PR.
- Градиенты/клипы в SVG: id — уникальные на каждый экземпляр рисунка (см. `uidSvg` в `fx/src/fx3.js`, строка 7),
  иначе в Chrome рисунок теряет заливку, если первый экземпляр с тем же id лежит в скрытом блоке.
- **Эффекты на телефоне и ноутбуке одинаковые** (решение 19.10): по ширине экрана меняется только раскладка и
  размер, но не число частиц, капель, фильтры и петли. Облегчение — только при «простых спецэффектах»
  и `prefers-reduced-motion`. Новый код любого раздела не должен добавлять облегчений по `isPhone`.
- Ноутбук 1366×660 и 1920×1080, телефон 430×932 и 390×844 (Safari — 430×740).

   Прогноз («−4», клетки) — только с «Подсказками», как сейчас.

## PH — Телефон и оснастка

Эталоны: `A5Phone.html` (кадры 1–7 и пояснения под ними) и `A5Rig.html`. Решения пользователя (19.10):

- **На телефоне эффекты и море — полностью как на ноутбуке** (feTurbulence, blur, петли, все капли). Сейчас в `fx/*.ts`
  `isPhone(ctx)` уменьшает число частиц, искр, капель (например, `motes` 24 вместо 46) — вернуть полные числа.
  Оставить уменьшение только там, где иначе не помещается по размеру (например, 4 корабля Армады вместо 6) — список
  таких мест в PR. Облегчение — только при «простых спецэффектах».
- Оснастка общая для ноутбука и телефона. «Фон под рукой» на ноутбуке — полоса под рукой (стол вокруг остаётся
  «Вещи на столе»), на телефоне — фон всей нижней панели.

Части (каждая — свой коммит):

1. **Планшеты и стол на телефоне** (кадры 1, 1б): два сверху, два снизу, море между ними; шапка — картинка, короткое
   имя, ✓ готов, веер с числом карт, медальон Легенды, без капитана. Корпус — доски во всю ширину и крупное число
   (17 px); Паруса/Пушки/Команда — один значок и «2/3», ноль — красным и перечёркнутым значком; подписи убраны,

## SND — Звук

Пользователь кладёт файлы в `public/sfx/raw/` и список `public/sfx/raw/sources.txt` (файл — что это — откуда —
лицензия). Сейчас в игре один звук «ваш ход» на WebAudio (`src/ui/sound.ts`).

1. Прочитать `sources.txt`. Брать только CC0 / CC-BY (для CC-BY — строка в «Об игре» / титрах). Файл без лицензии
   или с непонятной — не использовать, перечислить в PR.
2. Обработать (ffmpeg): обрезать тишину, нормализовать громкость (≈ −16 LUFS для эффектов, тише для фона), моно,
   `.ogg` (opus) + `.mp3` для Safari; положить в `public/sfx/`. Исходники `raw/` в сборку не попадают. Общий вес
   ≤ 1,5 МБ, фон моря — отдельно, грузится после старта партии.
3. Модуль звука: одна точка `play(name, {volume, rate})` поверх WebAudio, небольшое случайное изменение высоты (±4 %)
   у повторяющихся звуков (выстрелы, всплески), ограничение одновременных (не больше 6), разблокировка на iPhone по
   первому касанию (как сейчас `armSound`).
4. Привязка к событиям — через существующие клипы анимаций (там, где клип стартует/бьёт), а не через движок:
   выстрел, полёт ядра, попадание/треск доски, всплеск/промах, пожар, ремонт, гибель (взрыв, треск, крики чаек),
   «Тревога!» (колокол), карта в руку/сыгранная карта, «ваш ход», начало раунда, погода (гром, ветер, волны),
   Легенды (Кракен, Армада — горн, бутылка — «чпок», Джек — тиканье компаса), Победа/поражение. Что из этого есть в
   файлах — решить по `sources.txt`; чего нет — пропустить, список в PR.
5. ⚙: «Звук» вкл/выкл, громкость эффектов, громкость моря (фон). По умолчанию — включено, умеренно. Фон моря —
   тихая петля, выключается вместе со звуком.
6. Тесты: unit — карта событий → звуки; e2e — звук не ломает темп (tempo) и ничего не играет до первого касания.

Проверка: список «событие → файл» в PR; вес `public/sfx/`. e2e: tempo, fx-turn, phone.
