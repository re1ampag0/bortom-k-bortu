Анимации стола · эталон

Эталон для Claude Code. Каждая сцена — настоящие события движка (партии ботов, как их видит игрок после eventsFor). Чистая функция planfx строит из них клипы, проигрыватель показывает. Ядро = 1 урон: попавших ядер ровно столько, сколько урона посчитал движок. Слой эффектов не ловит нажатия; нажатие по столу сразу показывает итог; карты в руке и журнале открываются всегда.

Скорость Спецэффекты Включено «уменьшение движения» — игра так и покажет: сразу итог. Выберите скорость, чтобы посмотреть анимацию.
