# Эталон анимаций (уровень 1 + Легенды)

Открыть: `anim-demo.html` двойным щелчком (шрифты — из `../fonts`).

- 62 сцены на **настоящих событиях движка**: Залпы (18), Реакции (13), корабли (5), ход (3),
  Легенды (4), все 17 карт моря, макеты интерфейса P2 и P3.
- Справа — события и клипы; у каждого выстрела проверка «долетело N = урон движка N».
- Скорость: медленно ×1,6 / обычно / быстро ×0,6 / мгновенно. «Простые» спецэффекты — без частиц.
- Параметры адреса: `?cap=<сцена>` — режим съёмки, `&speed=1.6`, `&rich=0`, `#<сцена>` — открыть сцену.

Как переносить в игру — **`PORTING.md`** (обязательно прочитать перед задачами A1–A4, S1, L1).

Проверено в Chromium (1366×660 и 430×740): 62 сцены без ошибок консоли; 4484 точки над планшетами,
картами, колодой и значком моря — ни одну не перекрывает слой эффектов; нажатие по столу во время показа
сразу показывает итог; карта в руке открывается во время показа и не обрывает его.

Пересобрать сцены (нужны дампы партий): `python3 build-data.py data/game-data.json > data.js`,
`python3 build-scenes.py games.json data.js scenes.js synth.json`. Обычно не нужно.
