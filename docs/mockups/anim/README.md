# Эффекты на столе — словарь анимаций

Образцы в этой папке (открываются в браузере, код можно брать):
- `volley2.html` / `volley2.gif` — бортовой Залп по кораблю напротив (одобрен автором);
- `diag.html` / `diag.gif` — Залп по диагонали: одно ядро уходит в воду с меткой «Диагональ −1»;
- `storm2.html` / `storm2.gif` — карта моря «Буря» (одобрена): тучи, молнии, дождь, улёт в значок;
- `sea.html` / `sea-card.png` — как выглядит карта моря;
- `fonts/` — шрифты для образцов (в игре они из @fontsource).

Пиксель в пиксель не копировать: размеры и места берутся из настоящих планшетов на столе
(ноутбук 1366×660, iPhone 430×740). Только своя графика (SVG/CSS) — никаких кадров,
постеров и узнаваемых образов из фильмов.

## Главный принцип: ядро = 1 урон

В Залпе вылетает столько ядер, сколько у стрелявшего Пушек. Каждый модификатор виден глазами:
плюс — лишнее ядро со своей меткой, минус — ядро, которое не долетает, тоже с меткой.
Попавших ядер ровно столько, сколько урона посчитал движок. Метки берутся из того же
разбора урона, что и плашка рядом («Пушки 2 · Диагональ −1 · …»).

Анимации привязаны к **операциям движка** (fx в данных карт), а не к названиям карт:
новая или изменённая в редакторе (этап 9) карта анимируется сама. Свою «подпись» имеют только
Легенды, карты моря, особенности кораблей и несколько ярких карт (уровень 3).

## 1. Залп

**Объявление.** Сыгранный Заряд вылетает из руки (у противника — из-за края стола) и ложится
рядом с плашкой разбора; стрелявший и цель подсвечиваются. Здесь открывается окно Реакций.
Сами ядра летят только после того, как Реакции решены.

**Выстрел** (как volley2): по вспышке и клубу дыма у борта на каждое ядро, шаг 0,14 с;
ядра летят прямо к нужной шкале цели; попадание — вспышка, щепки, цель вздрагивает, красная
рамка, клетки краснеют и гаснут по одной, число на шкале меняется, пилюля «−N» у числа.

**Шкала цели — вид снаряда:**
| Шкала | Снаряд | Попадание |
|---|---|---|
| Корпус | ядро | щепки |
| Паруса — «Книппели» | два ядра на цепи, крутятся | рваная парусина |
| Команда — «Картечь» | облачко мелкой дроби, по облачку на 1 урон | пыль, клетки Команды гаснут |
| Пушки — «Огонь по орудиям», «Прицельный огонь» | ядро | искры по строке Пушек |

**Плюсы — лишние ядра (со своей меткой):**
| Откуда | Как выглядит |
|---|---|
| «Ядра», «Залп всей батареей», «Один выстрел» | обычные ядра, метка с названием карты |
| «Греческий огонь» | горящее ядро со шлейфом; после попадания на цели загорается Пожар |
| «Калёные ядра» (на цели Пожар) | раскалённые красные ядра |
| «Зов глубин» (цель уже ранена) | зеленовато-призрачные ядра |
| «Оплаченный залп» | бочонки Пороха из Трюма превращаются в ядра |
| «Чёрная метка» | два ядра летят точно в чёрную метку на планшете |
| «Поднять флаги!» | флажок над стрелявшим, ядро «Флаги +1» |
| «Ясное небо» (напротив) | ядро с золотым бликом |
| Совместный залп | лишнее ядро вылетает с борта союзника, метка «Совместный +1» |
| Всплытие «Голландца», «Всплытие», «Из пучины» | ядро вылетает из-под воды с пузырями и брызгами |

**Минусы — ядра, которые не долетают:**
| Откуда | Как выглядит |
|---|---|
| Диагональ −1 | ядро уходит в сторону и падает в воду, всплеск (как diag) |
| «Буря» −1 | ядро сбивает ветром, падает в волну |
| «Водоворот» | ядро закручивает в воронку посреди стола |
| «Уйти по ветру», «Двойная обшивка», «Тяжёлый борт» | ядра отскакивают от борта с искрами |
| «Прикрыть бортом» −1 | ядро вязнет в борту прикрывшего, метка |
| «Лунный свет» (по Команде) | одно облачко дроби проходит сквозь серебристую Команду |

Без штрафа за диагональ («Бросить якорь», «Прицельный огонь», «Из пучины», «Строй линии»,
«Мальстрём») ядра летят по диагонали прямо, у плашки — метка «без штрафа: <карта>».
«Туман»: диагональ нельзя выбрать — на столе диагонали закрыты дымкой, анимации выстрела нет.

**Особые Залпы:**
- «Залп с обоих бортов» — дым с двух бортов, ядра расходятся на обе вражеские цели
  (по Пушкам каждой). Если Реакция «Всё по плану» — вторая половина ядер не вылетает.
- «Зомби у пушек», «Сердце Дейви Джонса», «Всплытие» — второй Залп сразу после первого,
  та же анимация; у «Сердца» перед этим сердце на «Индеворе» бьётся дважды, красная нить
  к «Голландцу», у «Голландца» гаснет 1 клетка Команды.
- Без Реакций («Один выстрел» с План:, «Из пучины», «Всплытие», после «Ужаса» или «Подкупа»)
  — на плашке штамп «Без Реакций», окно Реакций не открывается.

## 2. Реакции

Карта Реакции вылетает из руки защищающегося (или переворачивается из Плана с лентой
«План!») и встаёт рядом с плашкой. Плашка пересчитывает урон. Потом выстрел по новым правилам.

| Тип | Карты | Анимация |
|---|---|---|
| reduce | «Уйти по ветру», «Двойная обшивка», «Тяжёлый борт» | часть ядер отскакивает с искрами; у «Уйти по ветру» планшет чуть отклоняется, у «Двойной обшивки» на борту вспыхивает вторая обшивка |
| reduce_all | «Водоворот» | воронка в центре стола до конца хода, каждое следующее ядро −1 туда |
| cancel | «Чёрные паруса в ночи» | цель темнеет, как в ночи, все ядра проходят мимо в воду |
| cancel | «Уйти на глубину» | «Голландец» уходит под воду (как Погружение), ядра шлёпают по воде |
| cancel | «Банка с землёй» | над «Жемчужиной» трясётся банка; Залп или карта «Голландца» рассыпается в песок (против Кракена щупальца отдёргиваются) |
| cancel_charge | «Всё по плану» | Заряд у плашки перечёркивается чернилами и выцветает; ядра — обычные |
| cancel_crew | «Зомби-офицеры», «Морская пехота» | перед строкой Команды встаёт заслон, дробь в него вязнет; у «Морской пехоты» после абордажа у нападавшего гаснет 1 Команда |
| redirect | «Прикрыть бортом» | союзный планшет выдвигается вперёд, ядра меняют цель, одно вязнет (−1) |
| counter | «Ответный залп», «Тяжёлый борт», «Огненная стена», «Ответный огонь», «Ответ из пучины» | после попаданий — ответ от защищавшегося к стрелявшему: ядра по Пушкам, языки пламени + Пожар, ядро + книппель, призрачная дробь |
| steal | «Ловкость рук» | разыгранная карта после розыгрыша не уходит в сброс, а улетает в руку укравшего |
| escape | «Джек ускользает» | см. Легенды |

Окно Реакций по-прежнему не выдаёт руку (пауза 1–2 с у нападающего).

## 3. Приказы «Это не Залп»

Пушки не стреляют — урон наносит то, что изображено на карте. Карта в центре, затем удар.

| Карты | Анимация |
|---|---|
| «Бочки с порохом» | бочки падают на сетке к цели, фитиль, взрыв — −4 Корпус |
| «Ничего личного» | сургучная печать «Компания» хлопает по планшету, клетки Корпуса гаснут |
| «Сделка с Сяо Фэном» | узкие лодки выскакивают из-за края стола, бьют по Корпусу и Парусам |
| «На абордаж!», «Абордаж рыболюдей» | абордажные крюки летят к планшету напротив, перекрещенные сабли над Командой (у рыболюдей — зеленоватые) |
| «Пленная русалка» | волна с блеском у планшета напротив, −1 Команда, карта в руку |
| «Ужас Карибского моря» | тёмный туман с черепом на цели, −2 Команда, слот Реакций с замком до конца хода |
| «Указ о казнях», «Жатва» | волна по всем вражеским планшетам сразу: свиток / коса-тень, по −1 Команде |
| «Сто лет службы» | 2 Души улетают со шкалы, у врага −2 Команда, у «Голландца» +2 Команда |
| «Брандер» | горящий кораблик плывёт к цели, два Пожара |
| Пожар после попадания | язычок пламени садится на планшет (до 3 штук) |

## 4. Статусы — штампы на планшете

Появляются с «ударом» (штамп), висят, пока действуют, по нажатию — подробности (это уже есть).

| Статус | Карты | Значок | Когда срабатывает |
|---|---|---|---|
| Пожар (до 3) | «Греческий огонь», «Брандер», «Огненная стена» | язычки пламени | в начале хода своей команды угольки бьют в Корпус по 1 за Пожар; тушение — сброшенная карта падает на огонь, пар |
| Чёрная метка | «Чёрная метка» | чёрное пятно | ядра летят в неё, «+2» |
| Переговоры | «Право на переговоры» | белый флаг, строка Пушек бледнеет | в ход противника кнопка Залпа у корабля закрыта |
| Блокада | «Блокада» | цепь вокруг планшета | Ремонт и смена мест закрыты |
| Вуду | «Кукла вуду» | кукла с иглой | каждая сыгранная этим кораблём карта — укол, −1 Команда |
| Без Реакций | «Ужас», «Подкуп» | замок у слота Реакций; у «Подкупа» — монеты сыплются к вражеской команде | до конца хода |
| Под водой | Погружение | планшет опускается вниз, синее наложение, пузыри; Пожары гаснут с паром | всплытие — брызги, первый Залп «Всплытие +1» |
| Флаги | «Поднять флаги!» | флажки над обоими своими кораблями | до конца хода |
| Строй линии | «Строй линии» | пунктир по диагоналям «без штрафа» | до конца хода |
| Лишние карты | «Жестокая дисциплина», «Приказ лорда Беккета», «Казна», «Флот на горизонте» | у счётчика карт хода загораются лишние ячейки | до конца хода / раунда |

## 5. Порох, карты, Души, ремонт

- **Порох:** бочонки летят в Трюм с «+N» («Выкуп за пленников», «Бизнес есть бизнес»,
  «Каперский патент», доход в начале хода, «Торговый караван»). Оплата — бочонки исчезают из Трюма
  (Залп, Перестроение, Меч, Казна, стоимость карты). «Ограбление банка» — бочонок перелетает
  из вражеского Трюма в свой. «Сырой порох» — волна заливает оба Трюма, половина бочонков тает.
  Проданная карта превращается в бочонок и летит в Трюм.
- **Казна Компании:** 2 бочонка → монета → лишняя ячейка карты хода у «Индевора».
- **Карты:** добор — рубашки едут из колоды в руку (себе — переворачиваются лицом).
  «Анжелика», «Тёрнер и Суонн» — карта едет к союзнику. «Обезьянка Джек» — рубашка из руки
  противника к себе (видят все, лицо — только укравший). «Колокол „Голландца“» — звон кругами,
  из каждой вражеской руки уходит карта в сброс (лицом — сброс открыт). «Шпион Мерсер» —
  глаз над рукой противника; лицо руки видит только играющий, остальным — карта в сброс.
  «Игра в кости лжеца» — две рубашки в центре, одновременно переворачиваются, обе едут к
  победителю. «Компас Джека», «Безумный план», конец хода «Жемчужины» — карта рубашкой
  к месту Планов. «Тиа Дальма» — веер трёх верхних карт моря: сыгравшему лицом, остальным рубашками.
- **Души:** огонёк от раненой Команды врага летит в шкалу Душ «Голландца»; трата — огоньки
  уходят из шкалы туда, где работают (ремонт, «Сто лет службы», Кракен).
- **Ремонт:** клетки зеленеют по одной, «+N» зелёным. «Фонтан молодости» — с водяными искрами,
  «Сердце бьётся» — Души превращаются в клетки, «Вербовка утопленников» — зеленоватые.

## 6. Движение кораблей

- **Смена мест** (Перестроение, «Меч Тритона», «Строй линии», «Течение», «Мальстрём»,
  «Джек ускользает»): планшеты плавно меняются местами по дуге (~0,6 с, FLIP-анимация),
  у «Меча» над вражескими планшетами проходит зелёный блик, у «Мальстрёма» — вращение вокруг
  воронки. «Рифы» — при смене мест о камни, −1 Корпус. «Штиль» и «Блокада» — смена мест закрыта.
- **Гибель:** планшет кренится, медленно уходит вниз с пузырями, становится серым контуром
  «Затонул».

## 7. Легенды (золотые, длиннее остальных ~2,5–3 с)

- **«Джек ускользает»** — «Жемчужина» начинает тонуть (крен), замирает, вспышка, надпись
  «Ускользнул!», Корпус становится 2, корабли команды меняются местами.
- **«Корабль в бутылке»** — планшет цели сжимается в силуэт бутылки, хлопает пробка,
  бутылка уплывает; потом обычная гибель.
- **«Армада Компании»** — ряд силуэтов парусников вдоль края стола со стороны Компании, залп
  по обоим вражеским планшетам: −2 Корпус и −1 Паруса каждому.
- **«Кракен»** — 3 Души уходят со шкалы, стол темнеет, снизу вокруг цели поднимаются щупальца
  (своя графика), сжимают — тряска, −4 Корпус, −2 Команда, уходят вниз.

## 8. Начало хода — по порядку

Баннер хода → доход бочонками в Трюм → эффекты моря начала хода («Девятый вал» — волна,
−1 Паруса ходящим; «Мальстрём» — смена мест) → Пожары жгут Корпус → напоминание о Вуду
(кукла подрагивает) → добор. Каждый шаг короткий, всё вместе ≤ 2 с.

## 9. Карты моря (у каждой своя анимация, как «Буря»)

Вход: карта выезжает крупно в центр (как в storm2), эффект ~2 с, карта улетает в значок
в строке состояния. «Весь раунд» — после этого тихий фон до конца раунда (без мельтешения,
выключается вместе с движением). «Сразу» — эффект и изменения на планшетах.

| Карта | Вход | Фон раунда |
|---|---|---|
| Штиль | волны разглаживаются, паруса-значки обвисают | гладкая вода, смена мест закрыта |
| Попутный ветер | полосы ветра проносятся через стол | редкие лёгкие полосы |
| Туман | туман наползает с краёв, диагонали закрываются | дымка в углах стола |
| Буря | готово — storm2 | косой дождь стихает до редких капель |
| Девятый вал | огромная волна проходит через стол | в начале хода — волна по ходящим, −1 Паруса |
| Мальстрём | воронка закручивается в центре | медленно вращается |
| Ясное небо | тучи расходятся, солнечные лучи | тёплый свет, ядра напротив с бликом |
| Русалки | нотки и блики из воды у кораблей, клетки Команды «уплывают» (−1 у Команды ≥ 3) | — |
| Тортуга | фонари, кружки, бочонки; затем выбор «сколько Пороха на карты» | — |
| Ром в волнах | бочонки рома качаются у бортов, +1 Команда всем | — |
| Торговый караван | купеческие паруса проходят по горизонту, бочонки в оба Трюма | — |
| Сырой порох | волна заливает Трюмы, половина бочонков тает | — |
| Рифы | из воды показываются камни по краям | камни; смена мест — удар о камни |
| Гроза | одна молния бьёт в корабль с самыми высокими Парусами, −2 Паруса | — |
| Флот на горизонте | силуэты парусов на горизонте | лишняя ячейка карт хода у всех |
| Лунный свет | стол темнеет, восходит луна, строки Команды серебрятся | сумерки, серебряная Команда |
| Течение | стрелки течения, обе команды меняются местами | — |

## 10. Уровни (что делать первым)

1. **Обязательно:** Залп со всеми плюсами, минусами, шкалами и Реакциями; смена мест;
   Погружение и всплытие; гибель; Пожары; Порох; карты (добор, передача, кража); ремонт;
   начало хода; «Сердце Дейви Джонса»; общая анимация для любой незнакомой операции.
2. **Потом:** приказы «Это не Залп» по типам, штампы статусов, Души, 4 Легенды, 17 карт моря.
3. **Если хватит:** «подписи» отдельных карт (бочки, печать, лодки Сяо Фэна, брандер, кости, колокол).

Длительности при скорости «обычно»: Залп 1,6–2,4 с; приказ ~1,2 с; карта моря ~2–2,5 с;
Легенда 2,5–3 с; смена мест 0,6 с; гибель 1,8 с; начало хода ≤ 2 с.
