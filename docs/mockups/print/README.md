# Эталон печатной карты (утверждён пользователем)

- `V2type.html` / `V2type.jpg` — лицо карты, вид «В-2 стекло», оттенок стекла в цвет **типа**.
- `V2ship.html` / `V2ship.jpg` — то же, оттенок стекла в цвет **корабля**. Выбор между ними ещё не сделан.
- `Icons2.html` / `Icons2.jpg` — значки «было → стало»: медали типа, монета Пороха, склянка Душ.
- `Backs2.html` / `Backs2.jpg` — нынешние рубашки колод и памятка «Как читать карту» (памятка со старым черепом —
  обновить на склянку).
- `icons/` — значки типов из игры и склянка Душ; `art/` — шесть готовых портретных картинок и четыре рубашки.

Страницы `.html` открываются в браузере (шрифты Alegreya грузятся с Google Fonts). Размер карты на странице —
300 × 420 px = 63 × 88 мм (1 px ≈ 0,21 мм). Вёрстку переносить в генератор печати в миллиметрах.
Задача: `docs/tasks/print-kit.md`.
