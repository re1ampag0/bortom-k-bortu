# weather-window

Основание: main8d6f922(PR75), отдельная ветка weather-window.
План подтверждён; поправки пользователя о репликах и неизвестном «было» учтены.

## Этап1 — каркас и тело

SeaSheet делегирует WeatherWindow. Размер920×600, пропорциональный масштаб,
закрытие пользователем. Статичная штурманская карта из chart_bg принятого
генератора, карта моря236×352 с медальоном wx.ts, подписи/текст/эффект из данных,
строки кораблей2×2 и команд, Боцман с дудкой из макета, история из LogLine.sea,
настоящие размеры колоды/сброса с учётом карты на столе/сразу. История, текущая
карта и доступный «Тиа Дальмой» верх колоды открываются по прежним правилам.
При просмотре неактивной карты нынешние шкалы к ней не применяются.
Сцена в шапке пока только фон: живые сцены — этапы2–4. Телефон — этап5.

Общий код ship-window выделен в scene-window/PreparedScene.tsx, assets.ts,
scene.css, fonts.css. ShipScene оставлен адаптером того же manifest; его вид,
часы, CSS-переопределения телефона и жизненный цикл сохранены. Кэш объединяет
одновременные decode одного изображения, хранит один набор сцены на владельца.
Второй проигрыватель для погоды не создаётся. Сами ship-window-ресурсы неизменны.

Чистая модель weather-window/model.ts читает публичные данные. Для мгновенных
эффектов берутся сохранённые результаты журнала между открытием моря и началом
хода: последующий бой не попадает в эти строки. Исторические числа не выводятся
обратно из нынешних шкал. При отсутствии записи — текущее («Трюм5», «Команда2»),
без выдуманного «было». У перенаправлений просмотра скрытые карты не раскрываются.
Есть5 unit-проверок на Бурю, Попутный ветер, Грозу, Сырой порох и границу событий;
они пока НЕ запускались: по заданию npm test один раз в конце.

### Реплики: изменения по поправке пользователя

| Карта | Новый текст/подстановка |
|---|---|
| Девятый вал | Паруса определяют запас Реакций. Волна уменьшает этот запас в начале хода. |
| Мальстрём | Команда меняется местами в начале хода. По диагонали можно бить без штрафа. |
| Русалки | Чем больше команда, тем опаснее песня. Малочисленную команду Русалки не заденут. |
| Ром в волнах | Полной команде ром не поможет. Остальным море вернёт матросов. |
| Сырой порох | Море забирает половину Пороха; потери округляются вниз. |
| Гроза | Молния ищет самые высокие Паруса. Когда все спущены, удара нет. |
| Торговый караван | Трюм вмещает не больше {cap} Пороха; лишнее сгорит. Тратьте, пока купцы не уплыли. |
| Ясное небо | Кто стоит напротив, получает на {seaClear} больше. Улыбайтесь — солнце же! |
| Лунный свет | Урон по Команде на {seaMoon} меньше — абордаж сегодня бьёт слабее. |

Поля подставляются из действующих data.econ.cap/data.rules, не из примера.
Все17 реплик хранятся в data/game-data.json seaTips; правила/движок/сервер не менялись.
