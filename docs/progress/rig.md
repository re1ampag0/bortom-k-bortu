## Решения пользователя

- Решения по умолчанию 1–6 из плана приняты: (1) круглые кнопки 64 px внизу справа на ноутбуке, 48 px вверху и на телефоне;
  (2) «Залп с планшета» — из ячеек пушек, число выстрелов = число живых пушек, прежние вспышки на краю заменяются; (3) «Фальшборт» по
  умолчанию, сохранённые `brass`/`wood` читаются как умолчание, тест `clarity.test.ts:110` меняется по спецификации; (4) штурвал —
  отдельный элемент, на 1366×660 допустимо «только на больших экранах»; (5) статусы на телефоне — бляха вместо значка в строке
  ярлыков, правило «три и больше — только бляхи» это PH2; (6) `cannon2` — значок пушки на шкале.
- **Правка к (г):** на ноутбуке «Фон под рукой» — только полоса под картами руки; стол вокруг («Вещи на столе», компас `compassHero`)
  остаётся в обоих вариантах, компас при «Палубе» НЕ прятать. «Без компаса» относится к самой полосе палубы и к телефону. Проверить
  кадром, что полоса палубы не закрывает компас и вещи.
- В этой сессии — только (а), (б), (в); (г)–(е) — новой сессией.

## Журнал

### (а) «Ход окончен» / «Огонь!» / «Реванш»

- `art/oak.ts` — медальон (латунный обод, тёмный диск с точечным кольцом, блик; якорь без каната или дуло пушки `MUZZLE_S` из
  `phone_tpl.html`), id уникальны на каждый рисунок. `OakButton` в `Table.tsx` (`.oak-btn` в конце `game.css`): дубовая доска, винная
  вставка, золотая надпись; ноутбук 300×66 (медальон 54), телефон 260×56 (44). Подпись — текст кнопки (e2e `toHaveText('Ход окончен')`
  сохранён), `data-testid` прежние. Длинная подпись («Сейчас ход Компании») — мельче; узкая кнопка (телефон 390 px рядом с тремя
  кнопками) — `@container` уменьшает медальон и шрифт, иначе обрезка «…» (на 390 px кнопка ≈ 190 px, не 260: рядом «Журнал», «Правила»,
  «Отменить»; раскладка нижней панели — часть PH1, не менялась, только отступы кнопок слева).
- Применено: `Game.tsx` (оба места `end-turn`), `Panels.tsx` («Огонь!», дуло, под ним «1 Порох»; `data-testid="fire"`, `aria-disabled` как
  было, при запрете — причина в `title`), `Victory.tsx` («Реванш» — тот же `OakButton`; старые `.v-med/.v-pan/.v-rematch` убраны, подпись
  «те же корабли, новая партия» / «согласны 1 из 2» прежняя). Удалён `anchorSvg` из `art/medal.ts` (не нужен). Старые стили `.end-turn`
  (белая, бордовая) убраны, остались `.ready` (свечение) и `[aria-disabled]`.
- Кадры: `docs/screenshots/rig/a-end-{table,fire,victory}-{1366x660,430x932}.png`, `a-end-table-390x844.png`, `a-end-fire-390x844.png`,

`npx playwright test` запись скриншотов переписывает `docs/screenshots/stage7,p7,p8,a5-windows` — откатывать `git checkout`).
