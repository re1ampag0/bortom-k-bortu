## Решения пользователя по ходу

- Сверху — Трюм верхней команды («Трюм Компании» или «Трюм пиратов»); «Перестроение» — только у нижней команды.
- Телефон (≤ 700 px): журнал и нижняя панель работают как сейчас.
- Перед удалением верхней `team-row` — проверить `sea.ts tableCtx` и e2e fx-sea.

## Задачи для следующих пакетов

- **FX-A:** вспышки клеток шкал (`setTrack`, Девятый вал) анимируют `background` клетки; у значков A5 фон защищён
  `!important`, поэтому вспышка видна только кольцом (`boxShadow`). Вернуть вспышку в новом виде (например, свечение
  значка через `filter` или подсветку под значком).
