## Решения и продолжение

1. Не повышать0,5%, не маскировать спорные области и не объявлять различия сглаживанием без достаточного основания.
2. Скрипты являются отдельной диагностикой, не входят в игру. Их собственные часы/накладные расходы запрещено использовать как измерение FPS приложения.
3. Фиксировать адаптер на всю пару; результаты разных протоколов не сравнивать между собой. Предыдущие промежуточные эксперименты оставлены локально, в отчёте использована последняя законченная диагностическая пара.
4. Для места под lossless-архивы старый чистый вспомогательный fx-main-reference переведён на sparse checkout без дубликатов screenshots. Git-история и снимки в Git сохранены; это обратимо.
5. Браузерные launcher-скрипты поддерживают CHROMIUM_PATH и браузер Playwright вне Linux. Это меняет хеш кода launcher-а; зафиксированная Linux-пара сохранена отдельно.

**Точка продолжения:** сначала добиться доказуемого допуска А/A (включая пространственный разбор), затем снять полный эталон и только после него начинать погоду/вехи1–8. Не использовать эту ветку как готовое ускорение и не продолжать оптимизации поверх неподтверждённого эталона. Вопрос пользователю не задавался; остановка соответствует прямо разрешённому условию задачи.
