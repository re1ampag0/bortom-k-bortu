# fx-smooth-a

База main 096d871 (слиты #57 ui-5 и #58 fx-ambient). Ветка claude/charming-hamilton-qiiyje (выбор пользователя).
Только способ отрисовки и работа React: картинка, длительности, порядок и сюжет анимаций не меняются.
Чужие файлы не трогаются: fx/volley.ts, fx/sprites.ts, fx/legends.ts; в fx/primitives.ts — минимум строк.

## Почему memo в fx-canvas не уменьшил рендеры

- `gen` и `busy` — `useState` в `useFxQueue`, а хук вызывается из тела `Game`: каждый `bump()` выполняет всю функцию
  `Game` с пробными ходами движка (`volleyTargets`, `heartTargets`, `abilityButtons`, `tryAction`, `playOptions`).
  memo детей не уменьшает число рендеров самого `Game`.
- У рядов планшетов `revision={fx.gen}` — на каждый bump все планшеты перерисовываются; `Plank` без memo, получает
  новый `tableView`, новые массивы кнопок и обработчики.
- В deps метки `tableInteraction` есть `botBusy` (в нём `fx.busy`) и `banner`.
- bump на каждом шаге очереди, часть через `flushSync` (после клипа, `renderWith`).

## Шаг 0 — счётчики клипа (сделано)

- `src/ui/game/perf/clip.ts`: окно = показ (от busy до конца). Сцена — список клипов, кадры/с мин (по секундам) и
  средние, длинные задачи (`longtask`; в Safari его нет — пишется «нет в этом браузере» и кадры >50 мс), рендеры Game
  (число, сумма, максимум: `performance.now()` в начале тела и в `useLayoutEffect`), анимации внутри SVG на весь стол
  (в момент вызова `A()`, ключ «клип · вид элемента»). Без `?perf=1` хук в `A()` — `null`, часы в `Game` не читаются.
  Показ без единого клипа таблицу не перезаписывает.
- Табличка `?perf=1`: блок «Последний клип» и кнопка «Скопировать числа» (clipboard, запасной путь — выделение текста).
  Принудительные пересчёты и слои — только в замере эмулятора.
- Замер эмулятора: `scripts/fx-smooth-a/measure.mjs` (+ `trace-metrics.mjs`). Отдельная e2e-сборка без сжатия с
  Vite-плагином счётчиков; в сайте их нет. 390×844, DPR 3, CPU ×4, seed 1, **один игрок против ботов**: в режиме
  «двое за одним устройством» шторка обрывает показ выстрела (журнал: «показ прерван: … шторка (шёл shot)»),
  на iPhone так не играют. Нажатия — с hit-test. Конец сцены — показ окончен, результат на столе, снова ход игрока.
  - volley — Залп «Жемчужины» по «Индевору» без Заряда (announce + shot);
  - hit — тот же Залп с Зарядом «Залп с обоих бортов» (попадания по двум кораблям);
  - card — «Право на переговоры» по «Индевору»;
  - armada — Легенда «Индевора» за Компанию (клип legend 16 с); legend — её появление (окно до конца legendIntro);
  - idle — стол в покое 10 с.
  Recalculate Style = union `UpdateLayoutTree` главного потока; в скобках — принудительные (внутри JS).
  Scripting = union JS-событий. Длинные задачи — `RunTask` > 50 мс из трассы.

## Шаг 1б — хранилище показа и подписчики (сделано)

- `FxLayer.tsx`: `gen`/`busy` больше не `useState` в теле `Game`. Снимок `{display, gen, epoch, hidden, logFrom, busy}`
  во внешнем хранилище; `bump()` публикует новый снимок, `flushSync(bump)` по-прежнему рисует подписчиков синхронно —
  в тот же момент клипа. Новые действия в очереди публикуются в том же layout-эффекте (флаги и строки журнала
  скрыты до отрисовки). `epoch` растёт при обрыве показа (пропуск, нажатие, Undo): всё, что клип менял руками, строится заново.
- `Game.tsx`: стол рисуют подписчики — `PlankRow` (ряд планшетов), `Shown` (строка статуса, фишка моря, трюмы),
  `ShownLog` (журнал, «Последнее: …», книга журнала), `FxBusy` (кнопки «Быстрее / До конца хода / Пауза»),
  `BotDriver`/`HoldReset` (ход ботов после показа, сброс паузы). `data-fx-busy` на корне ставится через ref по снимку;
  CSS `.game.fx-busy` → `.game[data-fx-busy]` (fx.css, game.css, phone.css), `TableThings.tsx` — тот же атрибут.
- `Table.tsx`: `Plank = memo(…)`. С тем же stamp сравнивается только показанное: корабль, порох стороны, активная
  сторона, союзники (утонул, Души), `s.turn`, скрытые флаги и ревизия корабля. Ревизия (ключ `.tracks`) растёт, когда
  меняются поля этого корабля или `epoch`; у трюмов — когда меняется порох.
- Погода (`FxLayer`): её собственная проверка читала `board.clientWidth` сразу после коммита — принудительная раскладка
  на каждом рендере слоя (профиль: 182 мс за Залп). Теперь `drawWeather` вызывается при смене её входов (море, места,
  утонувшие, rich, выключатель), размер — через уже существующий ResizeObserver.

## Как воспроизвести

`node scripts/fx-smooth-a/measure.mjs LABEL [сцены…]` — сборка в tmp/fx-smooth-a/LABEL-dist;
`--reuse` — без пересборки, `--dist LABEL` — чужая готовая сборка, `--root DIR` — собрать другую копию кода.
