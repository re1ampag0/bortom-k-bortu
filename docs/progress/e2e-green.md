# e2e-green

База: свежий main `5f097c58` (PR #85). Ветка `e2e-green`, отдельный worktree; ветка и исходники `fps-pass` не менялись.

## Выполняется

Полный исходный прогон: `E2E_WEBKIT=1 CI=1 npm run e2e -- --reporter=list,json`, 209 тестов, один worker, собранный e2e-сайт. JSON результата: `docs/measurements/e2e-green/main-e2e.json` (появится после окончания). Прогон стартовал до правок; сервер продолжает отдавать неизменённую сборку main. Список всех падений и классификация будут заполнены по завершении.

В среде установлены браузеры версии Playwright 1.56.1: Chromium 141.0.7390.37 и WebKit 26.0. Для WebKit недостающие Debian-библиотеки распакованы локально, подключены в каталоги sys/lib обоих MiniBrowser. Контрольный запуск WebKit открыл страницу. Это локальная настройка среды, конфигурация CI не менялась.

## Обязательная подготовка рендера

В `FxLayer` mount-time warmup мог пропустить банк частиц, когда начальное море уже играло. Затем пулы наклеек ещё десять секунд ждали простоя. Поэтому ранний Залп переключался на SVG: сторож зарегистрировал 101 анимацию внутри SVG на весь стол. Перед клипами теперь создаётся/проверяется банк частиц; перед shot/counter/sink/legend/jack проверяется подготовка пулов, перед legend/jack готовится вступление. Ресурсы создаются вне показа, T.* и события не менялись.

Существующий `perf-guard` прошёл **58,324 с**, прежний общий лимит **60 с сохранён**. Его проверки/исключения не изменены. Единственное изменение ожидания: конец полного быстрого потопления ждёт до20с вместо общего actionTimeout8с, потому что реальный полный клип измерен в8,633с. Диагностическая копия с увеличенным общим бюджетом использовалась только для установления причины; итоговый адресный запуск проверял исходный общий лимит60с.

`hull impact: no debris or damage before arrival; the plate stays above wreckage` прошёл без изменения ожиданий после подготовки банка/пулов. `perf-before.json`, `guard-final-focused.json`, `net-impact.json`, `fast-sink-timing.json`, `typecheck-renderers.txt` в measurements/e2e-green. В timing-пробе были ошибки403 шрифтов локального dev-сервера; его разрешённые пути затем исправлены. Это не ошибки игры и не замер FPS; использовать пробу только как подтверждение длительности >8с.

Пожар: устаревшее «−1 Корпус…» заменено на полный текущий текст из PR #84 (`98ae1d89`). Все проверки невидимой зоны касания, открытия/закрытия и сохранения показа сохранены, адресный тест прошёл. Журнал: распознаётся предложение «… бьёт …», введённое PR #85; прежние проверки скрытия результата до клипа и появления после пропуска, ссылок карты и статусов сохранены. Адресный тест прошёл19,4с.
