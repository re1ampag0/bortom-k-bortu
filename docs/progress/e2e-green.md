## Выполняется

Полный исходный прогон: `E2E_WEBKIT=1 CI=1 npm run e2e -- --reporter=list,json`, 209 тестов, один worker, собранный e2e-сайт. JSON результата: `docs/measurements/e2e-green/main-e2e.json` (появится после окончания). Прогон стартовал до правок; сервер продолжает отдавать неизменённую сборку main. Список всех падений и классификация будут заполнены по завершении.

В среде установлены браузеры версии Playwright 1.56.1: Chromium 141.0.7390.37 и WebKit 26.0. Для WebKit недостающие Debian-библиотеки распакованы локально, подключены в каталоги sys/lib обоих MiniBrowser. Контрольный запуск WebKit открыл страницу. Это локальная настройка среды, конфигурация CI не менялась.
