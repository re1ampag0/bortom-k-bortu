## Как пользоваться на iPhone

Открыть адрес игры с ?perf=1 (если параметры уже есть — &perf=1). «Части» — выбрать, что отключить.
№10 включает «Простые спецэффекты» только для диагностики, не меняя настройку ⚙.
Сначала записать 20 с без отключений, воспроизведя Залп; затем тот же сценарий с одной отключённой
частью, каждый раз отдельная запись. Дождаться итога и нажать «Копировать»; на HTTP, если автоматическое
копирование недоступно, выделить текст результата. Передать обе строки пользователю/разработчику.
?perf=0 полностью выключает диагностику; выбор частей сохраняется для следующего включения.
