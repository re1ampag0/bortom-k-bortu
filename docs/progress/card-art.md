## Решения

- Уточнение лимита60КБ из плана принято пользователем: считаем до отложенных изображений, их трафик отдельно. Полная production-сборка не запускалась по ограничению проверок; точный прирост её JS остаётся для CI/проверки сборки.
- Эталонные файлы расположены прямо в docs/mockups/2026-10-26/, не в img/.
- Внешняя область карты сохраняет исходную высоту148px, на низком ноутбуке132px (фактический main), а рисунок168px растёт вверх. Первоначальное предположение146px оказалось неверным; исправлено по прямым замерам main. Итоговый сдвиг зон0.
- На длинных полных картах сохранены flavor и весь текст, высота растёт: скрытие flavor из промежуточных классов reference не переносилось.
- Лифт расширен до224px, положение ограничено краями игрового корня. Обработчики выбора/действий прежние, движок/данные/протокол не менялись.
- Кадр общего окна карты на телефоне готовится вызовом существующего onCard через React fiber (настоящий первый тап открывает лифт). Это capture-only, исходный интерфейс не изменялся ради кадра.
- Подготовка кадров использует единственное монтирование React через capture-only замену StrictMode→Fragment, как в предыдущем ui-polish; production-код не менялся.
- Сравнение геометрии с локальным сервером main/ui-polish5405, новая версия5406; одинаковые записи/размеры. Скрипты кадров и замера в scripts/card-art/.
- Все существующие тесты/testid сохранены, e2e не запускались. Реальный iPhone/WebKit не проверялся.

Реализация, кадры и разрешённые проверки завершены. Точный production-пэйлоад и заголовки хешированных файлов этой сборки не проверены без сборки. PR создаёт пользователь.
