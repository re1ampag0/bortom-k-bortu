## Решения

- Вложенные материалы v2 объединены part1→part2; совпадения заменены part2.
- Локальная и сетевая расстановка используют одну доску. В фазе расстановки
GameState ещё не существует; проверяется фактический RoomInfo, без выдачи
порядка. viewFor/сервер/протокол не менялись.
- Рисунок сцены взят из генераторов v2; большие SVG существуют только при
офлайн-подготовке, в игре — декодированные картинки и HTML-обёртки.
- Сцены имеют отдельные банки картинок: одновременно видимые плитки команд
не вытесняют друг друга из decode-кэша. Тяжёлый manifest меню загружается лениво.
- Светлая тема не реализуется. Исходные материалы сохранены после переноса.
- Никаких промежуточных проверок. Запускались только рабочие генераторы арта.

## Дополнительные решения и исправления

- Маски/blur отражений нельзя оставлять на движущемся родителе: экспортёр
для menu запекает весь такой фрагмент в четыре кадра. Вспышки, которые являются
чистой прозрачностью готовой картинки, сохраняют кривую opacity; огонь — кадры.
- Корень (#menu-art) выбирает адаптер menus/scenes.mjs. Изменения экспортёра
для составных transform и отражений ограничены menu-флагом; прежние размеры
viewport и корни экспортов ship/weather сохранены.
- Картинки всех сцен и WebP-фонов декодируются через один ограниченный пул
вне документа. У видимых сцен отдельные ссылки на свои готовые картинки:
одновременные плитки команд не вытесняют друг друга.
- При окне Правил или Настроек фон меню приостанавливается; после закрытия
возвращается в состояние настроек. Переключение эффектов не переписывает perf.
- filters не создаёт альтернативную графику: живых фильтров в слоях нет,
они уже запечены. Этот переключатель останавливает движение, готовая тень остаётся.
- RulesWindow выведен порталом в body: масштаб игрового стола не уменьшает окно.
- Во время обязательной проверки QR обнаружено наследование старых размеров
.qr: квадрат растягивался и обрезался. Исправлены квадрат, вложенный SVG и поле;
после исправления jsQR прочитал ссылку с центральным якорем.
- Для кадров в dev скрипт заменяет StrictMode на Fragment только в загружаемом
ответе main.tsx: старый NetClient иначе закрывается strict-effect cleanup.
Код приложения, сервер и протокол ради кадров не менялись. Сборка не запускалась.
- Для отсутствующих на досках состояний (ошибки, ожидание, сохранения, свободные
места, чужая комната) сохранены настоящие данные и действия. Демо-игроки и
демонстрационные Порох/шкалы не подставляются.
