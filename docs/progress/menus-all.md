# menus-all

План M1→M2→M3→M4 подтверждён. Одна ветка от свежего main.
Проверки только после M4: typecheck, tests/view.test.ts, декодирование QR.

## Вехи

1. Материалы v2 объединены в docs/mockups/menus: сначала part1, затем part2;
совпадающие файлы заменены новыми, вложенные папки удалены. Реализация ещё не начата.
Светлая тема сохранена только как исходный материал, в игру не переносится.

2. M1: общий модуль menus, исходные сцены v2 подготовлены офлайн существующим
экспортёром окон (Main/Phone, плитки команд, палитры моря); карты — WebP.
Старт, подготовка и монета перенесены; логика seed/вариантов/сохранений сохранена.
Общие части используют HTML transform/opacity, decode-кэш, IO/visibility/reduced-motion.
Проверки не запускались. Следующее: M2, расстановка и шторка.

3. M2: общая доска расстановки для локальной/сетевой игры, неизвестные силуэты
не получают порядок противника; свои корабли и шкалы, канаты/диагонали,
шторка с морем команды и новой кнопкой. Публичный RoomInfo уже не содержит
тайного порядка; сервер/протокол не менялись. Добавлен единственный новый тест
в tests/view.test.ts (пока не запускался). Следующее: M3.

4. M3: сетевой вход/комната переоформлены, причалы с сухими кораблями, новые
подписи действий, статусы, панель партии, QR с ECC H/полем4 и якорем14% ширины.
Сервер, протокол, разрешения действий и нормализация кода сохранены.
Проверка QR отложена до конца M4. Следующее: Правила и Настройки.

5. M4: RULES-PLAYER.md скопирован дословно; новое окно Правил с главами,
поиском, Боцманом, таблицами, схемой Залпа, памяткой и телефонными чипами.
Полный RULES.md доступен отдельно. Памятка перенесена с числовыми подстановками
из данных. Настройки сгруппированы Показ/Игра/Вид стола, новые иконки,
сегменты скорости/эффектов, компас и подписи. Существующие настройки сохранены.
Общий фон дополнен настоящим anim_layer из chart.py (курс, кильватер,
стрелка, змей, чайки, буруны). Следующее: только финальные проверки и кадры.

## Решения

- Вложенные материалы v2 объединены part1→part2; совпадения заменены part2.
- Локальная и сетевая расстановка используют одну доску. В фазе расстановки
GameState ещё не существует; проверяется фактический RoomInfo, без выдачи
порядка. viewFor/сервер/протокол не менялись.
- Рисунок сцены взят из генераторов v2; большие SVG существуют только при
офлайн-подготовке, в игре — декодированные картинки и HTML-обёртки.
- Сцены имеют отдельные банки картинок: одновременно видимые плитки команд
не вытесняют друг друга из decode-кэша. Тяжёлый manifest меню загружается лениво.
- Светлая тема не реализуется. Исходные материалы сохранены после переноса.
- Никаких промежуточных проверок. Запускались только рабочие генераторы арта.
