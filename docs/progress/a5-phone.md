# Пакет 6а «a5-phone»: телефон — раскладка

Спецификация — `docs/mockups/a5/TASKS-2.md` (PH: решения пользователя, части 1, 2, 3). Эталон — `A5Phone.html` кадры 1, 1б, 6,
`png/phone-1-turn.png`, `phone-1b-safari-740.png`, `phone-6-card.png`. Ветка — `claude/eloquent-mccarthy-xny5mj` (от main с PR #48).

Решения пользователя к плану: у поднятой карты под «Сыграть» — строка мелких кнопок «Продать · Передать · Потушить», только
те, что можно нажать сейчас (недоступных не видно); всё по кадру 1 — и верхняя строка, и нижняя панель, и подпись руки вместо
вкладок; «Палуба» на телефоне: пушка слева внизу под рукой, фонарь справа сверху, ни пушка, ни фонарь не перекрывают подпись
руки, карты и нижнюю панель. Проверки — только `npm run typecheck`; vitest, e2e, sim не запускаются (проверяет CI), новых
тестов нет; e2e, которые ломает новый вид, правятся по смыслу.

Все стили телефона — в `src/ui/game/phone.css` (только `@media (max-width: 700px)`, подключён после `game.css`); в разметке —
`.narrow`-элементы и ветки `usePhoneLayout()`. Ноутбук 1366×660 после каждой части сравнивается с кадром «до» попиксельно.

## Журнал работы

- 1: верхняя строка — латунная плашка «ПИРАТЫ · I», плашка моря со значком и «Море · весь раунд / Буря: Залпы −1», шестерёнка;
  строка-подсказка — бумажная полоса 32 px. Трюм противника — строкой над морем («ТРЮМ КОМПАНИИ», лоток бочонков, «4/8»),
  свой — под морем («ТРЮМ ПИРАТОВ», лоток, «2/8»), справа «Перестроение» — тёмная дубовая плашка с круглым знаком и зелёным
  «бесплатно». Планшет: картинка корабля 32×20, короткое имя, ✓, веер, медальон; выбранный корабль — в золотой рамке вместо
  «ВЫБРАН» (веер виден); Корпус — доски-значки во всю ширину + число 17 px (полоска `.bar` скрыта, клипы бьют в доски);
  Паруса/Пушки/Команда (и Души у «Голландца») — значок + «2/3», на минимуме — красное число и значок «потерян»; подписи убраны,
  нажатие на значок — окно с правилом (тексты из памятки `memo.ts → TRACK_RULE`); при выборе цели окна выключены, веер прячется
  (в шапке «i»). Кнопки планшета: одна — во всю ширину, две — делят ряд (вид «значок · имя | цена»), три и больше — по трети с
  прокруткой, как было. Море не меньше 64 px, при нехватке высоты сжимается рука (карты уходят под нижнюю панель). Нижняя
  панель: «Журнал», «Правила» — квадратные значки с подписью, «Отменить», «Ход окончен» со строкой «„Месть“ готова — ждёт вас».
  Ноутбук 1366×660 — без отличий от кадра «до» (разница пикселей > 40 — нет).
  e2e по смыслу: `phone.spec` — выбор корабля касанием по числу Корпуса (значки шкал открывают правила; `.tracks` больше не
  блок); `u3-layout.spec` — «кнопки одной ширины» → одна-две кнопки заполняют ряд, три и больше — одной ширины в своём планшете.
  typecheck — зелёный. Кадры: `docs/screenshots/a5-phone/1-turn-430x932.png`, `1-turn-vs-ref.png`, `1b-safari-430x740.png`,
  `1b-safari-vs-ref.png`, `1-laptop-1366x660.png`.
