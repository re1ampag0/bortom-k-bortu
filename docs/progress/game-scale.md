## Исходные кадры
scripts/game-scale/scenario.ts готовит обычное сохранение:seed1, два законных окончания хода, начало второго раунда, пять карт у Жемчужины. Без изменения движка/данных. Chromium, DPR3 для ширины≤1100; WebKit в среде отсутствует по предыдущей задаче.

На320×568 исходный стол действительно уходит ниже окна: нижняя панель не видна, рука срезана. Любое исправление должно включаться только при фактической нехватке места или на незакреплённых размерах.

## Пункт 1 — игровая высота

Игровая ветка stage подписана на visualViewport.resize, resize и orientationchange через game/layout.ts. При ширине≤700px --app-h/--app-w задаются и при k1; desktop k1 сохраняет прежний null, большие окна сохраняют прежнюю формулу. При фокусе в текстовом поле уменьшение высоты удерживает прежние размеры до закрытия клавиатуры. gamescale=0 возвращает старую ветку. Ветка menuscale не изменена, выключатели независимы.

Before — отдельный worktree /workspace/game-scale-before на4463481, сервер5361; after — рабочий game-scale, сервер5362. Один capture.mjs, системный Chromium, DPR1 ноутбук/DPR3 телефон. Обычное сохранение, второй раунд,5 карт, журнал, Реакция. Прокрутка window/root/stage/board сброшена. Шрифты и картинки декодированы заранее. Часы Playwright остановлены; подготовленные сцены/SMIL стоят на0, бесконечные CSS-анимации зафиксированы в начальном кадре, конечные завершены с commitStyles/cancel. Это только способ съёмки: код игры и видовые свойства не подменяются, масок/цветового допуска нет. Подготовка состояний скриптом использует DOM click; попадание настоящих кнопок отдельно записывает audit через elementFromPoint.

Именно фиксация CSS-кадра устранила нестабильность снимков старого helper. ## Пункт 2 — телефон

Игра использует измеренную высоту и при k1: нижняя панель остаётся в visualViewport, её исходный safe-area padding сохранён. На коротком телефоне скрытый низ карт доступен вертикальной прокруткой полосы, действие выбора/поднятия/игры карты не переписывается. Hand.tsx не изменён.

Перестроение проверяется по настоящему правому краю кнопки. Небольшая нехватка ширины: компактный вариант без декоративной иконки, с прежними словами/ценой, внутри того же прямоугольника. Большая: перенос кнопки на следующую строку. Смена режима пересчитывается при resize, без нового rAF. Подписи узкого телефона получили непрозрачную деревянную подложку ровно в своём месте, если сзади пушка: декорация за текстом не видна. Координаты пушки/руки не менялись ради Н2. Новых элементов, классов, testid и текстов нет; добавлены только атрибуты/стили раскладки существующих узлов. Это исключение из буквального запрета любых атрибутов DOM нужно для независимого gamescale=0.

Замеры fitGame не читают позиции во время клипа; мутации fx-layer/fx-scars игнорируются. В конце клипа раскладка обновляется один раз.

Карта390×844: after/390x844/diff-table.png и diff-reaction.png. Жёлтые прямоугольники — подписи и кнопка с их отрисовкой, розовый — различия.
