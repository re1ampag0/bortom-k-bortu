## Исходные кадры
scripts/game-scale/scenario.ts готовит обычное сохранение:seed1, два законных окончания хода, начало второго раунда, пять карт у Жемчужины. Без изменения движка/данных. Залп Жемчужины по Индевору даёт настоящую Реакцию. Скрипт кадров capture.mjs снимает стол, журнал и Реакцию, без тестовых утверждений. Chromium, DPR3 для ширины≤1100; WebKit в среде отсутствует по предыдущей задаче.

На320×568 исходный стол действительно уходит ниже окна: нижняя панель не видна, рука срезана. На390×844 подписи и пушка визуально пересекаются, но этот размер защищён Н2: изменение его вида запрещено. Любое исправление должно включаться только при фактической нехватке места или на незакреплённых размерах.

## Пункт 1 — игровая высота

Игровая ветка stage подписана на visualViewport.resize, resize и orientationchange через game/layout.ts. При ширине≤700px --app-h/--app-w задаются и при k1; desktop k1 сохраняет прежний null, большие окна сохраняют прежнюю формулу. При фокусе в текстовом поле уменьшение высоты удерживает прежние размеры до закрытия клавиатуры. gamescale=0 возвращает старую ветку. Ветка menuscale не изменена, выключатели независимы.

Before — отдельный worktree /workspace/game-scale-before на4463481, сервер5361; after — рабочий game-scale, сервер5362. Один capture.mjs, системный Chromium, DPR1 ноутбук/DPR3 телефон. Обычное сохранение, второй раунд,5 карт, журнал, Реакция. Прокрутка window/root/stage/board сброшена. Шрифты и картинки декодированы заранее. Часы Playwright остановлены; подготовленные сцены/SMIL стоят на0, бесконечные CSS-анимации зафиксированы в начальном кадре, конечные завершены с commitStyles/cancel. Это только способ съёмки: код игры и видовые свойства не подменяются, масок/цветового допуска нет. Подготовка состояний скриптом использует DOM click; попадание настоящих кнопок отдельно записывает audit через elementFromPoint.

Именно фиксация CSS-кадра устранила нестабильность снимков старого helper. Диагностика main-self/ показывает, что старый helper давал176 различающихся пикселей даже между двумя запусками main; эти кадры не являются итоговыми доказательствами.
