## Исходные кадры
scripts/game-scale/scenario.ts готовит обычное сохранение:seed1, два законных окончания хода, начало второго раунда, пять карт у Жемчужины. Без изменения движка/данных. Залп Жемчужины по Индевору даёт настоящую Реакцию. Скрипт кадров capture.mjs снимает стол, журнал и Реакцию, без тестовых утверждений. Chromium, DPR3 для ширины≤1100; WebKit в среде отсутствует по предыдущей задаче.

На320×568 исходный стол действительно уходит ниже окна: нижняя панель не видна, рука срезана. На390×844 подписи и пушка визуально пересекаются, но этот размер защищён Н2: изменение его вида запрещено. Любое исправление должно включаться только при фактической нехватке места или на незакреплённых размерах.
