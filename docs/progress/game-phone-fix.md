# game-phone-fix

База: main 0e3adbe (игровой код 3b68988), ветка game-phone-fix.
Задание: приложенный пользователем текст, 13 пунктов; макеты docs/mockups/2026-10-26/.

## Ход работы
Пункты 1–8, 11: изменена телефонная геометрия, ровный ряд руки, оформление кнопок/шкал,
подпись капитана вне потока, фонарь и привязка света. Это промежуточный этап,
кадры и проверки ещё не запускались: только в конце по заданию.
Далее: диагностика/прокрутка, лист/свиток и Планы, финальные кадры и две проверки.

## Решения
- В загруженном main картинки лежат непосредственно в docs/mockups/2026-10-26/,
  хотя ссылки галереи содержат img/. Используются одноимённые реальные файлы.
- На430×932 изменяются только заказанные элементы телефона. Их новый вид не может
  совпасть с прежним веером/фонарём; остальные зоны сравниваются отдельно.

Пункты9–10: диагностика только по URL, закрытие ×, удаление старого флага; общий
scrollbars.css без стандартных scrollbar-color/width в WebKit-ветке.
Пункты12–13: общий пергамент, нижний лист/свиток, настройка view.play; цена/Трюм
из настоящего состояния, закрома с двумя местами. Обработчики и ограничения выбора
сохранены. Следующий этап: кадры, исправления по ним, итоговые проверки/отчёт.
