# game-phone-fix

База: main 0e3adbe (игровой код 3b68988), ветка game-phone-fix.
Задание: приложенный пользователем текст, 13 пунктов; макеты docs/mockups/2026-10-26/.

## Ход работы
Пункты 1–8, 11: изменена телефонная геометрия, ровный ряд руки, оформление кнопок/шкал,
подпись капитана вне потока, фонарь и привязка света. Это промежуточный этап,
кадры и проверки ещё не запускались: только в конце по заданию.
Далее: диагностика/прокрутка, лист/свиток и Планы, финальные кадры и две проверки.

## Решения
- В загруженном main картинки лежат непосредственно в docs/mockups/2026-10-26/,
  хотя ссылки галереи содержат img/. Используются одноимённые реальные файлы.
- На430×932 изменяются только заказанные элементы телефона. Их новый вид не может
  совпасть с прежним веером/фонарём; остальные зоны сравниваются отдельно.

Пункты9–10: диагностика только по URL, закрытие ×, удаление старого флага; общий
scrollbars.css без стандартных scrollbar-color/width в WebKit-ветке.
Пункты12–13: общий пергамент, нижний лист/свиток, настройка view.play; цена/Трюм
из настоящего состояния, закрома с двумя местами. Обработчики и ограничения выбора
сохранены. Следующий этап: кадры, исправления по ним, итоговые проверки/отчёт.

не доказательство всех возможных партий и не проверка настоящего браузера телефона.

## Решения и ограничения

- Утверждённые jpg находятся прямо в каталоге даты, не в img/. Часть названных
  крупных фрагментов (например plans-zoom-v2.jpg) отсутствует: использованы полные
  доски A/D и телефонные доски тех же элементов.
- Разница на430×932 необходима для прямых пунктов3–8/11; старый веер и верхний
  фонарь не сохраняются ради формального совпадения. Высокому телефону оставлено
  сопоставимое место под руку, чтобы смена её вида не увеличивала море.
- gamescale=0 оставляет прежнюю геометрию телефона, исходный веер/верхний фонарь.
  Новые настройки розыгрыша, диагностический флаг и общая прокрутка действуют
  независимо от выключателя геометрии.
- Душам в тесном заголовке освобождено место за счёт декоративной картинки
  «Голландца»; Легенда и число карт сохраняются. На430px остаются4 ячейки шкал.
- Проверка0/1/5 меняет только текстовое число в DOM для аудита ширины, без действий
  и без изменения данных/правил. Партия и заголовки пояснений остаются настоящими.
- Декоративный образец карты в листе не получает hand-card/data-fx-card:
  существующие e2e и эффекты не должны принять его за настоящую карту руки.
- Существующие testid и обработчики сохранены. Для нового вида добавлены
  декоративные обёртки и атрибуты раскладки; буквальная неизменность всего DOM
  несовместима с новыми листами/свитком. Тексты карт не редактировались.
- Под коротким листом телефон уступает место один раз по доступной высоте.
  Длинное содержимое прокручивается отдельно, действия вынесены вниз.
- Реакции сохраняют свой готовый компонент и выбор. У него тот же пергамент/синий
  цвет; на ноутбуке A использует нижнюю область, D область журнала. Его логику
  не заменяли новым потоком CardParamsPanel.
- Видимая полоса прокрутки7px нарисована внутри прежнего нативного желобка15px,
  чтобы не менять ширину содержимого. WebKit-ветка не задаёт scrollbar-color/width;
  Firefox получает thin внутри @supports. Скрытые карточные ленты остаются скрытыми.
- Реальное устройство и браузерные панели здесь не проверялись. Вариант D при
  скрытом боковом журнале на промежуточных ширинах701–1279 не входит в матрицу.
