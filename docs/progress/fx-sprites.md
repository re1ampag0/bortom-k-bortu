## Этап 2 — сделано

- sprites.ts: DocumentFragment на каждый стол, один шаблон на тип и ограниченный пул
  готовых экземпляров. Создание HTML/SVG и уникализация gradient ID только при подготовке.
  takeSprite не парсит и не расширяет пул; SVG статичен, spriteA разрешает только transform/opacity
  HTML-обёрток. Повторные размеры не копят неиспользуемые типы.
- FxLayer готовит Армаду при открытии/resize вне клипа; типы ship/smoke-light/smoke-dark/ball/shadow.
  Пока Армада всё ещё рисуется старым способом. Шаблоны и свободные экземпляры НЕ вставлены
  в документ, не прозрачны и не стоят за краем экрана. Нет фонового RAF у кэша.
- Отмена/clear/reset возвращают временные экземпляры в пул и отменяют анимации.
  Пауза снимает will-change, продолжение восстанавливает только у живых анимаций;
  окончание снимает его, задержка не держит will-change заранее. Постоянные следы сохраняются.
- check-pool.mjs: 5 типов, 172 свободных экземпляра, 3186 DOM-узлов вне документа;
  connectedPrepared=false, после показа/паузы/отмены тот же пул, connected sprites=0,
  ни одной анимации на SVG. pool-check.json.
- measure.mjs: оптимизированная e2e-сборка, Chromium430×932/DPR3/CDP CPU×4,
  та же реальная сцена armada, ручной старт штатной кнопкой fixture, без вмешательства в engine.
  До: clip41784мс; Paint9991.077мс (максимум на главный кадр4002.742),
  Raster2688.521мс (максимум1899.403 между BeginMainThreadFrame),
  худший RAF6883мс, 101 интервал>50мс, пик1015 слоёв/1004 рисующих.
  Paint union по каждому потоку — вложенные Paint не суммируются дважды. Raster потоки
  суммируются отдельно от Paint; CPU-время не выдаётся за длительность GPU.
- Покоя два измерения по2с: до и с подготовкой одинаково26 слоёв/21 рисующий,
  Paint0мс, Raster0мс. Подготовка не добавляет работы в покое. before/prepared-metrics.json
  и сжатые исходные трассы рядом; кадр первой фазы armada-before.png снят отдельно от замера.
  Скрипт capture.mjs использует одинаковые native keyframes/управляемые часы/Math.random.
- npm run typecheck — exit0. npm test и e2e в этом этапе не запускались.
