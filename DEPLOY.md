# Как запустить игру по сети

Игре по сети нужен **игровой сервер** — программа, через которую устройства игроков обмениваются ходами. Сервер раздаёт и сам сайт, поэтому игроки открывают в браузере адрес сервера.

| Способ | Когда | Что нужно |
|---|---|---|
| [1. Wi-Fi](#1-wi-fi-все-рядом) | все в одной комнате | ноутбук с Windows и общий Wi-Fi |
| [2а. Свой сервер, простой](#2а-простой-вариант-httpip8080) | играть из разных мест | VPS, адрес вида `http://<IP>:8080` |
| [2б. Свой сервер, с доменом](#2б-полный-вариант-домен-и-https) | то же + сайт на GitHub Pages | VPS и домен или поддомен |

Пресеты данных на сервере (загрузка из «Админка → Сервер») включаются паролем администратора — см. [3. Пароль администратора](#3-пароль-администратора-пресеты-на-сервере).

> **Важно.** Сайт на GitHub Pages (`https://re1ampag0.github.io/bortom-k-bortu/`) открыт по защищённому протоколу `https`. Браузер **не даёт** такой странице подключиться к серверу без `https` (к адресу вида `http://192.168.1.23:8080`). Поэтому для Wi-Fi и простого сервера открывайте игру **с адреса, который показал сервер**, а не с github.io. Если всё же открыть github.io, игра на экране «По сети» покажет понятную ошибку и подскажет нужный адрес.

## 1. Wi-Fi: все рядом

Один ноутбук с Windows становится сервером. Остальные (ноутбуки, телефоны, в том числе iPhone) подключаются к нему через тот же Wi-Fi. Интернет нужен только при установке.

### Шаг 1. Установите Node.js (один раз)

1. Откройте https://nodejs.org и скачайте версию **22 LTS** для Windows (файл `.msi`).
2. Запустите установщик и нажимайте «Next» до конца, ничего не меняя.
3. Проверьте: нажмите `Win + R`, введите `cmd`, нажмите Enter. В чёрном окне введите:
   ```
   node -v
   ```
   Должно появиться `v22…`. Если пишет «не является внутренней или внешней командой», перезагрузите компьютер и проверьте ещё раз.

### Шаг 2. Скачайте игру

1. Откройте страницу проекта на GitHub: https://github.com/re1ampag0/bortom-k-bortu
2. Нажмите зелёную кнопку **Code → Download ZIP**.
3. Откройте скачанный архив и нажмите «Извлечь всё». Удобнее распаковать в короткую папку, например `C:\bortom`.

### Шаг 3. Откройте командную строку в папке игры

Откройте распакованную папку (в ней лежат `package.json`, `DEPLOY.md` и другие файлы). Щёлкните по адресной строке Проводника вверху, сотрите путь, введите `cmd` и нажмите Enter — откроется чёрное окно уже в этой папке.

> Используйте именно `cmd` (командную строку), а не PowerShell: в PowerShell команда `npm` иногда отказывается запускаться.

### Шаг 4. Установите зависимости (один раз)

```
npm install
```

Займёт 1–3 минуты, нужен интернет. Предупреждения (`npm warn`) — это нормально.

### Шаг 5. Запустите сервер

```
npm run lan
```

Через несколько секунд в окне появится:

```
Сервер «Бортом к борту» запущен.
На этом компьютере откройте: http://localhost:8080

На других устройствах в той же Wi-Fi сети откройте: http://192.168.1.23:8080

Или наведите камеру телефона на этот код:
(QR-код)
```

Если Windows спросит **«Разрешить доступ?»** для «Node.js JavaScript Runtime» — поставьте галочку **«Частные сети»** и нажмите **«Разрешить доступ»**. Без этого другие устройства не подключатся.

**Не закрывайте это окно, пока идёт игра.** Остановить сервер — `Ctrl + C`.

### Шаг 6. Играйте

1. На ноутбуке откройте в браузере `http://localhost:8080` → **«По сети»** → впишите имя → **«Создать комнату»**.
2. В комнате появятся код из 5 символов, ссылка с кнопкой «Скопировать» и большой QR-код.
3. Остальные открывают ссылку, наводят камеру телефона на QR-код или открывают адрес из консоли (`http://192.168.1.23:8080`) → «По сети» → имя → код комнаты → «Войти».
   - На iPhone: камера → нажмите на появившуюся ссылку; или Safari → вписать адрес целиком, **с `http://`**.
4. Каждый садится на свой корабль («Сесть»; можно на оба корабля своей команды). На пустые места создатель сажает ботов. «Жребий» решает, кто за какую команду. Создатель нажимает **«Начать»**.

В следующий раз достаточно шагов 3 и 5: открыть `cmd` в папке игры и ввести `npm run lan`.

### Как узнать адрес, если консоль его не показала

В окне `cmd` введите:

```
ipconfig
```

Найдите раздел **«Адаптер беспроводной локальной сети Беспроводная сеть»** (или «… Wi-Fi») и строку **«IPv4-адрес»**, например `192.168.1.23`. Адрес игры: `http://192.168.1.23:8080`. Разделы со словами VirtualBox, vEthernet, WSL — не те.

### Если не подключается

- **Сеть Windows должна быть «Частная», а не «Общедоступная».** В «Общедоступной» Windows не пускает к ноутбуку другие устройства.
  Windows 11: Пуск → Параметры → Сеть и Интернет → Wi-Fi → нажмите на имя вашей сети → **Тип сетевого профиля: Частная сеть**.
  Windows 10: Пуск → Параметры → Сеть и Интернет → Wi-Fi → нажмите на имя сети → **Частные**.
- **Нажали «Отмена» в окне брандмауэра.** Панель управления → Брандмауэр Защитника Windows → «Разрешение взаимодействия с приложением или компонентом…» → «Изменить параметры» → найдите «Node.js JavaScript Runtime» → поставьте галочку в столбце **«Частные»** → ОК. Затем перезапустите `npm run lan`.
- **Гостевой или университетский Wi-Fi** часто не пускает устройства друг к другу (даже если интернет работает). Тогда раздайте интернет с телефона:
  iPhone — Настройки → Режим модема → «Разрешать другим»; Android — Настройки → Точка доступа.
  Подключите **ноутбук и всех остальных** к этой точке доступа, перезапустите `npm run lan` (адрес изменится, например на `http://172.20.10.2:8080`) и откройте новый адрес.
- **Ноутбук уснул — сервер остановился.** Держите ноутбук на зарядке и отключите сон на время игры:
  Пуск → Параметры → Система → Питание (Питание и батарея) → Экран и спящий режим → «При питании от сети переводить устройство в спящий режим» → **Никогда**.
  Не закрывайте крышку (или: Панель управления → Электропитание → «Действия при закрытии крышки» → «Действие не требуется»).
  Если всё же уснул — партия сохранена. Разбудите ноутбук (если окно закрылось — снова `npm run lan`), страницы игроков подключатся сами; если нет — обновите страницу.
- **На телефоне надпись «Сервер недоступен: проверьте, что ноутбук с игрой не уснул и вы в той же сети».** Проверьте ноутбук (не уснул ли, открыто ли окно с сервером) и что телефон в том же Wi-Fi, а не в мобильном интернете.
- **«Порт 8080 уже занят».** Сервер уже запущен в другом окне — закройте его. Или запустите на другом порту: `npm run lan -- --port 8081` (тогда и адрес будет `…:8081`).
- **PowerShell пишет «выполнение сценариев отключено».** Откройте `cmd` (шаг 3) или введите `npm.cmd run lan`.
- **Страница открыта с github.io и пишет про https.** Откройте адрес сервера (`http://192.168.1.23:8080`), а не github.io.

### Как обновить игру

Скачайте ZIP заново (шаг 2), распакуйте в новую папку и повторите шаги 3–5. Незаконченные партии и пресеты лежат в папке `server-data` — скопируйте её в новую папку, если хотите их сохранить. Файл `.env` с паролем администратора тоже скопируйте (или создайте заново, см. раздел 3).

## 2. Свой сервер (VPS)

Сервер в интернете работает круглосуточно, и играть можно из разных мест. Готовьте его, когда будете покупать VPS.

### Какой сервер заказать

VPS у любого российского провайдера (например, Timeweb Cloud, Selectel, REG.RU, Beget): **Ubuntu 24.04, 1 ядро, 1–2 ГБ памяти**, 10 ГБ диска и публичный IPv4-адрес. После заказа провайдер покажет **IP-адрес** (например, `203.0.113.10`) и **пароль root**.

### Войдите на сервер по SSH

На Windows откройте `cmd` и введите (вместо `203.0.113.10` — ваш IP):

```
ssh root@203.0.113.10
```

На вопрос `Are you sure you want to continue connecting` ответьте `yes`. Введите пароль (символы не отображаются — так и должно быть) и Enter. Все команды ниже вводятся в этом окне.

### Установите Docker одной командой

```
apt update && apt install -y docker.io docker-compose-v2 git
```

Проверка: `docker compose version` показывает версию.

> Если при запуске ниже появится ошибка скачивания образов (`429 Too Many Requests`, `timeout`, `denied` при обращении к `docker.io`), подключите зеркало и повторите команду:
> ```
> mkdir -p /etc/docker && echo '{ "registry-mirrors": ["https://mirror.gcr.io"] }' > /etc/docker/daemon.json && systemctl restart docker
> ```
> У многих российских провайдеров есть и своё зеркало Docker Hub — его адрес подскажет поддержка.

### Скачайте игру

```
git clone https://github.com/re1ampag0/bortom-k-bortu.git
cd bortom-k-bortu
cp .env.example .env
```

### 2а. Простой вариант: `http://<IP>:8080`

Без домена и сертификата: сервер раздаёт и сайт, и игру.

```
docker compose up -d
```

Первый раз сборка займёт 2–5 минут. Проверка:

```
curl http://localhost:8080/health
```

Ответ `{"ok":true,…}` — сервер работает. Теперь в браузере на любом устройстве откройте `http://203.0.113.10:8080` (ваш IP) → «По сети».

- Если не открывается снаружи: в панели провайдера разрешите входящий порт **8080** (раздел «Firewall» / «Сетевые правила»). Если на сервере включён `ufw`: `ufw allow 8080/tcp`.
- Сервер сам запускается после перезагрузки VPS.
- Играть — только с адреса `http://<IP>:8080`, не с github.io (см. «Важно» в начале).

### 2б. Полный вариант: домен и HTTPS

Нужен домен или поддомен, который указывает на IP сервера:

- свой домен (например, купленный `.ru`): в панели регистратора добавьте **A-запись** `@` (или поддомен `game`) → IP сервера;
- или бесплатный поддомен на https://www.duckdns.org: войдите (например, через GitHub), придумайте имя (`bortom` → `bortom.duckdns.org`), впишите в поле `current ip` IP сервера и нажмите «update ip».

Проверьте, что домен уже указывает на сервер: `ping bortom.duckdns.org` показывает ваш IP (бывает нужно подождать до часа).

Откройте файл настроек:

```
nano .env
```

Впишите домен и сайт, которому можно подключаться:

```
DOMAIN=bortom.duckdns.org
ALLOWED_ORIGINS=https://re1ampag0.github.io
```

Сохраните: `Ctrl + O`, Enter, `Ctrl + X`. В панели провайдера откройте порты **80** и **443**. Если простой вариант уже запущен, остановите его: `docker compose down`. Запустите:

```
docker compose -f docker-compose.https.yml up -d
```

Caddy сам получит сертификат. Проверка в браузере: `https://bortom.duckdns.org/health` → `{"ok":true,…}`. Играть можно прямо на `https://bortom.duckdns.org`.

**Подключить сайт на GitHub Pages к серверу:**

1. GitHub → репозиторий → **Settings → Secrets and variables → Actions → вкладка Variables → New repository variable**.
2. Name: `VITE_SERVER_URL`, Value: `wss://bortom.duckdns.org/ws` → «Add variable».
3. **Actions → Check and publish → Run workflow** (или следующее слияние в `main`) — сайт пересоберётся с адресом сервера.

Без пересборки адрес можно вписать вручную: «По сети» → «Адрес сервера» → `wss://bortom.duckdns.org` → «Подключиться».

### Обновление

```
cd bortom-k-bortu
git pull && docker compose up -d --build
```

Для полного варианта: `git pull && docker compose -f docker-compose.https.yml up -d --build`.

### Полезные команды

| Что | Команда |
|---|---|
| журнал сервера | `docker compose logs -f --tail 50` (выход — `Ctrl + C`) |
| остановить | `docker compose down` |
| перезапустить | `docker compose restart` |
| где лежат комнаты | папка `server-data/` (комната удаляется после 24 часов без действий) |

Для полного варианта добавляйте `-f docker-compose.https.yml` после `docker compose`.

## 3. Пароль администратора: пресеты на сервере

В «Админке» (ссылка внизу стартового экрана) на вкладке **«Сервер»** можно загрузить пресет данных на игровой сервер; тогда создатель комнаты выберет его в «Игра по сети → Создать комнату → Данные игры». Загружать и удалять пресеты может только тот, кто знает **пароль администратора**.

- Пароль придумываете вы сами и записываете **только** в файл `.env` рядом с сервером: строка `ADMIN_PASSWORD=…`. На сайте пароля нет, в git файл `.env` не попадает.
- Нет пароля (или строка пустая) — загрузка выключена: вкладка «Сервер» покажет ответ сервера «загрузка пресетов выключена». Список пресетов и игра на них работают и без пароля.
- Неверный пароль — ответ «Неверный пароль администратора» через секунду.
- Пароль — буквы, цифры и дефис, 12 знаков и больше: такой никто не подберёт. Не используйте пароль от почты или банка. Без пробелов, кавычек и знака `#` (после `#` в `.env` начинается комментарий).

### Wi-Fi (`npm run lan`) на Windows

1. Откройте командную строку в папке игры (раздел 1, шаг 3).
2. Создайте файл настроек из образца:
   ```
   copy .env.example .env
   ```
3. Откройте его в Блокноте:
   ```
   notepad .env
   ```
4. Найдите строку `ADMIN_PASSWORD=` и допишите после `=` свой пароль, без пробелов и кавычек. Должно получиться так, только вместо `ваш-пароль` — ваш:
   ```
   ADMIN_PASSWORD=ваш-пароль
   ```
5. Сохраните: `Ctrl + S`, закройте Блокнот.
6. Если сервер уже запущен — остановите его (`Ctrl + C` в его окне) и запустите снова:
   ```
   npm run lan
   ```
   В окне появится строка «Загрузка пресетов из админки: включена». Если там «выключена» — проверьте, что файл называется именно `.env` (не `.env.txt`) и лежит в папке игры рядом с `package.json`.
7. На этом ноутбуке откройте `http://localhost:8080` → «Админка» → «Сервер». Адрес сервера можно не вписывать: страница открыта с него. Введите пароль и нажмите «Загрузить на сервер».

### Свой сервер (Docker)

Файл `.env` лежит рядом с `docker-compose.yml` (его создали командой `cp .env.example .env`).

1. Откройте его:
   ```
   nano .env
   ```
2. Впишите свой пароль после `=` в строке `ADMIN_PASSWORD=` (вид: `ADMIN_PASSWORD=ваш-пароль`). Сохраните: `Ctrl + O`, Enter, `Ctrl + X`.
3. Перезапустите сервер, чтобы он прочитал пароль:
   ```
   docker compose up -d
   ```
   (полный вариант: `docker compose -f docker-compose.https.yml up -d`)
4. Проверка: `docker compose logs --tail 20` показывает «Загрузка пресетов из админки: включена».

Пресеты хранятся в папке `server-data/presets/` и переживают перезапуск и обновление сервера. Комната хранит свою копию данных пресета: если удалить или заменить пресет, начатые партии доиграются на старых данных.
