# Бортом к борту

Цифровой прототип настольной игры «Бортом к борту» — для тестов правил и баланса.

- Сайт: https://re1ampag0.github.io/bortom-k-bortu/ — игра на одном экране, против ботов, матч ботов.
- Игра по сети (каждый со своего устройства): **[DEPLOY.md](DEPLOY.md)** — по Wi-Fi с ноутбука (`npm run lan`) или на своём сервере.
- Правила — `RULES.md`, техническое задание — `docs/TZ.md`, ход работы — `docs/PROGRESS.md`.

Для разработчиков: `npm ci`, `npm run dev`, `npm test`, `npm run e2e`, `npm run lan` (команды — в `CLAUDE.md`).

## Админка: как сделать пресет основным

«Админка» — ссылка внизу стартового экрана (или адрес сайта с `?admin` в конце). Вкладки: «Данные» (редактор данных и пресеты), «Лаборатория» (сравнение двух наборов на партиях ботов), «Сервер» (пресеты игрового сервера).

1. «Данные» → «Новый пресет»: копия основных данных, которую можно менять. Пресеты хранятся в этом браузере; «Экспорт» сохраняет пресет в файл, «Импорт» загружает его обратно (например, на другом компьютере).
2. Поменяйте числа и тексты. Изменённые поля подсвечены, «↺» возвращает поле как в основном. Если поменяли числа эффекта, а текст карты нет, появится «Текст карты мог устареть».
3. Сыграйте на пресете: «Против ботов» или «На одном экране» → «Ещё» → «Данные игры». Сравните его с основным в «Лаборатории».
4. «Скачать как основной»: сайт проверит набор и 100 партий ботов и скачает файл `game-data.json`.
5. Откройте на GitHub папку `data` репозитория → «Add file» → «Upload files» → перетащите скачанный файл (имя ровно `game-data.json`) → «Commit changes». Или откройте `data/game-data.json`, нажмите карандаш «Edit», замените всё содержимое и нажмите «Commit changes».
6. Дождитесь зелёной галочки у коммита (вкладка «Actions»). Через несколько минут сайт обновится, и набор станет основным у всех. Красный крестик — в данных ошибка, сайт останется прежним.

Тесты правил и эталон баланса (`npm run sim:check`, 46,5 %) работают на замороженной копии `tests/fixtures/game-data.v0.3.json`, поэтому новые числа в `data/game-data.json` их не ломают.

## Пароль сервера

Загружать пресеты на игровой сервер («Админка → Сервер») может только администратор. Пароль задаёт владелец сервера в файле `.env` рядом с сервером — строка `ADMIN_PASSWORD=…`; как это сделать для `npm run lan` на Windows и в Docker — [DEPLOY.md, раздел 3](DEPLOY.md#3-пароль-администратора-пресеты-на-сервере). На сайте пароля нет; набранный в админке пароль хранится только до закрытия вкладки. Без пароля загрузка на сервер выключена, игра работает как обычно.
