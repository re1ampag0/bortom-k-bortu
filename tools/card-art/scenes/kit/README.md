# kit — свет, материалы, небо и вода для печатных сцен

Чистые функции (CommonJS) → строки SVG. Сцена 200 × 280 единиц, x вправо, y вниз. Правила стиля —
`docs/mockups/print/STYLE.md`. Стенды-проверки: `report/print/agents/kit/stand/*.cjs`, рендер —
`report/print/agents/kit/render-stand.mjs`.

```js
const K = require('../kit/index.cjs');
const light = { time: 'night', key: { type: 'moon', x: 146, y: 34, el: 24 }, haze: .35 };
module.exports = { name: '…', kind: 'deck', status: 'draft', cam: { x: 0, y: 0, w: 200 }, light,
  scene: u => {
    const L = K.makeLight(light, { horizon: 96 });
    const bg = K.sky(u, L, { horizon: 96 }) + K.sunMoon(u, L) + K.water(u, L, { horizon: 96, bottom: 152 }) + K.deck(u, L, { horizon: 96, top: 150 });
    const fg = K.castShadow(u, L, { x: 78, y: 206, w: 22, h: 26, horizon: 96 }) + K.contactShadow(u, 78, 206, 22, L) + K.shadeSphere(u, 78, 193, 13, L, 'iron');
    return [bg, fg];
  } };
```

Общее: `u` — суффикс сцены (первый аргумент везде). Каждый id — `k<имя><u>n<счётчик>`, не повторяется. Все
функции возвращают **одну строку** со своими `<defs>` внутри (кроме `mat` — она возвращает объект). Случайность —
только от `seed`. Соседним предметам давай разные `seed`.

**Порядок слоёв.** Тени (`castShadow`, multiply) и свет (`localGlow`, `sunMoon`, `fire`, `muzzleFlash`, screen)
смешиваются с тем, что нарисовано **раньше в той же группе**. Клади их прямо в слой сцены, не внутрь `<g>` с
`opacity`, `filter`, `clip-path` или `mask` — там смешивание отрезается от фона. Порядок: фон → опора (палуба) →
падающие и контактные тени → предметы → свет и дым поверх.

## Свет — `light.cjs`

### `makeLight(light, cam?)` → `L`

`light` — схема сцены (она же поле `light` файла сцены):

| Поле | Что это |
|---|---|
| `time` | `'night' \| 'day' \| 'dusk' \| 'fog'` — палитра неба, воды, тени (`PAL[time]`) |
| `key.type` | `'sun' \| 'moon'` — параллельный свет; `'point'` — фонарь, свеча, огонь |
| `key.az`, `key.el` | градусы. az: 0 — свет из глубины на зрителя (контровой), 90 — справа, 180 — из-за спины, 270 — слева; el — высота |
| `key.x`, `key.y` | место источника в картинке. Для солнца и луны можно дать `x, y` вместо `az` (и `el`) или наоборот — недостающее считается по камере. Для `point` — место лампы |
| `key.h`, `key.gy` | `point`: высота лампы над опорой, м; `gy` — y точки опоры под лампой (если не дан, считается из `h`) |
| `key.radius`, `key.z` | `point`: на этом расстоянии свет слабеет вдвое (130); доля света «на зрителя» (0,38) |
| `key.color`, `key.power` | цвет и сила (0..1) |
| `fill` | `{ color, power }` — небо, вода, отражённый свет: цвет собственных теней |
| `rim` | `{ az, color, power }` — контровой: тонкая светлая кромка у шаров и цилиндров |
| `locals[]` | `{ x, y, h, color, power, radius }` — фонари сцены: тёплый бок у форм внутри радиуса |
| `haze` | 0..1, плотность воздуха; `shadowTint` — свой цвет тени (необязательно) |

`cam` = `{ horizon: 108, cx: 100, f: 320, eye: 1.7 }` — горизонт (y), центр, фокус (ед.), высота глаза (м). По
ней строятся тени. **Передавай горизонт своей сцены.**

`L` содержит:
- `L.dx, L.dy, L.dz` — единичный вектор **на источник**: `dx, dy` в плоскости картинки (y вниз), `dz` — доля
  «на зрителя» (< 0 — контровой свет). `L.ux, L.uy` — то же направление единичным вектором в плоскости.
  Для точечного света это значение в центре картинки; для предмета бери `L.at(x, y)` → `{ dx, dy, dz, ux, uy, p, k }`
  (`k` — сколько силы дошло).
- цвета (hex): `L.keyColor` (= `lightColor`), `L.fillColor`, `L.shadowColor` (свет в тени), `L.reflexColor`,
  `L.rimColor`, `L.shadowTint` (цвет падающей тени: ночью сине-фиолетовый, у огня тёпло-коричневый, днём холодный),
  `L.shadowMul` (он же, поднятый до среднего тона — им тень умножает опору).
- `L.source` — `{ x, y }` источника в картинке или `null`; `L.front` — солнце или луна перед нами.
- `L.vanish(horizonY)` → `{ x, y, parallel, toward }` — точка схода теней на горизонте: под источником, если он
  перед нами (`toward`: тени идут к зрителю и расходятся); на противоположной стороне, если он за спиной;
  `parallel` — боковой свет, тени вдоль горизонта. Для `point` — `null` (тени идут от `L.keyBase(horizonY)`).
- `L.shadowAt(x, y, h, horizonY)` → `{ x, y, angle, len }` — конец тени столба высотой `h` (ед. картинки) с
  основанием в `(x, y)`; `angle`: 0 — вправо, 90 — вниз (к зрителю). Для своих теней и проверки `skel`.
- `L.tone(kind, I, x?, y?)` → hex: цвет материала при освещённости `I` (1 — лицом к свету, 0 — терминатор, −1 —
  от света). `L.ramp(kind, x?, y?)` → `{ lit, half, core, shadow, reflex, outline, spec }` — готовые тона для
  деталей, нарисованных руками (контур — `outline`).
- `L.ellipse(y, horizonY)` — сплюснутость круга, лежащего на опоре на высоте `y` (ry / rx): для днищ бочек и `ell`.
- `L.pal` — палитра времени: `sky[4]` (верх → горизонт), `sea[3]` (у горизонта → у зрителя), `cloudLit`,
  `cloudShade`, `fog`, `smoke`. `LIGHTS.pearl | revenge | endeavour | dutchman | sea` — готовые схемы колод.

### Материалы

`KINDS`: `iron, brass, oak, pine-deck, canvas, linen, leather, skin, rope, glass, water-wet, tar, paint-red,
paint-ochre, bone, coral`. Блик, рефлекс, просвет — по таблице `STYLE.md` (`MAT[kind]`).

**`mat(kind, L, { form, x1, y1, x2, y2, r, n, u })` → `{ defs, fill, id, ramp }`.** Градиент в `userSpaceOnUse`
по проекции света: свет → полутон → терминатор → тень → рефлекс. `defs` положи в сцену, `fill` — в `fill` или
`stroke` своей формы.
- `form: 'cyl'` — ось `(x1, y1)–(x2, y2)`, радиус `r`;
- `'sphere'` — центр `(x1, y1)`, радиус `r`;
- `'plane'` — противоположные углы грани и нормаль `n`: `'top' | 'front' | 'left' | 'right' | 'back' | 'bottom'`
  или `[x, y, z]` (x вправо, y вверх, z на зрителя);
- `'fold'` — складки ткани вдоль `(x1, y1)–(x2, y2)`, `r` — полуширина складки; градиент повторяется поперёк.
  Это ровные складки (рифы, занавес); неровные дорисуй тонами `ramp`. Парусина и лён против света светлеют.

```js
const hoop = K.mat('iron', L, { form: 'cyl', x1: 168, y1: 210, x2: 168, y2: 172, r: 15, u });
out += hoop.defs + `<path d="M153 202q15 7 30 0" stroke="${hoop.fill}" stroke-width="2.6" fill="none"/>`;
```

**`shadeCyl(u, x1, y1, x2, y2, r, L, kind, opts)`** — цилиндр от `(x1, y1)` до `(x2, y2)`: ствол, мачта, рука,
бочка. Блик — полоса вдоль оси на стороне света. `opts`: `r1, r2` — радиусы концов (сужение); `bulge` — пузо бочки
(0,14); `ell` — сплюснутость торцов (0 — вид сбоку; 0,2–0,35 — вид сверху; `cap: 'round'` — круглые концы);
`face: 1 | 2` — какой торец виден (1 — начало, 2 — конец); `outline: false | толщина`; `spec: false`;
`grain: false` (волокно дерева); `rim: false`; `seed`.

**`shadeSphere(u, x, y, r, L, kind, opts)`** — шар. Блик смещён к источнику на 0,3–0,4 r (при контровом свете
уходит на освещённый серп). `opts`: `outline`, `spec`, `rim`.

**`shadeBox(u, faces, L, kind, opts)`** — плоские грани: `faces = [{ pts: [[x, y], …], n, kind?, grain?: [dx, dy] |
false }]` в порядке отрисовки (дальние первыми). Тон грани — по нормали; у рёбер к свету — светлая потёртая линия.
**`boxFaces(x, y, w, h, ox, oy)`** → `[верх, бок, перед]` для ящика: перед — прямоугольник с левым нижним углом
`(x, y)`; задняя грань сдвинута на `(ox, −oy)` (`ox > 0` — виден правый бок).

### Тени и локальный свет

**`castShadow(u, L, { x, y, w, h, horizon, onto, wallY, opacity, d })`** — падающая тень стоящего предмета:
`(x, y)` — середина основания, `w` — ширина основания, `h` — высота (ед. картинки). Солнце и луна — к точке
схода, длина `h / tg(el)` с перспективой; `point` — веером от точки под лампой. Чёткая у основания, мягче к концу,
цвет `L.shadowMul` (multiply), не чёрная. `onto: 'water'` — бледнее; `wallY` — y подножия стены сзади (тень
поднимается по ней); `d` — глубина основания к ширине (1 — круглое). Основание должно быть ниже горизонта.

**`contactShadow(u, x, y, w, L, { ry, opacity })`** — тёмное «сиденье» под основанием `(x, y)` шириной `w`.

**`localGlow(u, loc, { squash, core })`** — тёплый круг света с затуханием: `loc = { x, y, color, power, radius }`
(элемент `locals` или точечный `key`). `squash` — сплюснутость (пятно на палубе 0,3); `core: false` — без ядра.

## Небо, вода, эффекты — `env.cjs`

| Функция | Что рисует |
|---|---|
| `sky(u, L, { horizon, stars, seed, top })` | небо от `top` (0) до горизонта по `L.time`, светлее вокруг источника; `stars`: число или `false` (ночью 70) |
| `sunMoon(u, L, { r })` | диск с ореолом в `L.source` (луна — с «морями»; в тумане ореол больше) |
| `cloud(u, L, { x, y, w, h, seed, far })` | облако объёмом: `x` — середина, `y` — плоский низ; свет со стороны источника, тень снизу; против света — светлая кромка. `far` 0..1 — бледнее, к тону горизонта |
| `cloudBank(u, L, { y, h, x0, x1, n, seed, far })` | ряд из `n` облаков с низом около `y` |
| `water(u, L, { horizon, bottom, swell, seed, glitter })` | море в перспективе до `bottom`: ряды зыби сходятся к горизонту, дорожка бликов под источником. `swell` 0..1; `glitter: false` или x дорожки |
| `foam(u, { x, y, w, seed, h, L })` | пена по линии касания с серединой `(x, y)`, шириной `w` |
| `reflection(u, svgBody, { y, h, L, opacity, stretch, seed })` | отражение `svgBody` строго вниз от ватерлинии `y` на глубину `h`: размыто, разорвано рябью, гаснет. Id внутри переименованы — то же тело рисуй и над водой |
| `splash(u, { x, y, w, h, seed, L })` | всплеск на воде в `(x, y)`: `seed % 3` — столб, низкая корона, столб в сторону |
| `fog(u, L, { y, h, density, seed })` | полоса тумана от `y` вниз на `h` |
| `smoke(u, L, { x, y, w, h, seed, wind, opacity, glow })` | дым от `(x, y)` вверх на `h`, ширина наверху `w`, `wind` −1..1; тень снизу, свет со стороны источника, против света светится. `glow: { color, power }` — подсветка огнём снизу |
| `fire(u, { x, y, w, h, seed, glow, wind })` | огонь на `(x, y)` слоями, искры, свой свет (`glow: false` — без него) |
| `muzzleFlash(u, { x, y, dir, len, seed, smoke, glow })` | вспышка выстрела у дула `(x, y)` вдоль `dir` (градусы: 0 — вправо, 90 — вниз), длиной `len`; `seed % 3` — копьё, короткий широкий сноп, раздвоенное пламя с боковыми струями |
| `deck(u, L, { horizon, top, bottom, vx, seed, kind, plank, wet })` | палуба в перспективе от `top` до `bottom`: доски сходятся в `(vx, horizon)`; при `point` — пятно света под лампой; `wet` — полоса света под источником |

```js
const ship = hullSvg;                                         // свой рисунок корпуса над водой
bg += K.reflection(u, ship, { y: 120, h: 24, L }) + ship + K.foam(u, { x: 100, y: 120, w: 60, L, seed: 4 });
fg += K.muzzleFlash(u, { x: 142, y: 96, dir: -8, len: 28, seed: 2 })
   + K.localGlow(u, { x: 150, y: 124, color: '#ffc070', power: .5, radius: 30 }, { squash: .3, core: false }); // пятно на воде
```

## Чего здесь нет

Кораблей, пушек, людей, предметов (бочка на стенде собрана в `stand/common.cjs` как пример). Новые общие детали —
с пометкой `KIT-CANDIDATE` в своей сцене; в `kit/` их переносит главная сессия.
