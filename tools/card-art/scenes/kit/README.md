# kit — свет, материалы, небо и вода для печатных сцен

Чистые функции (CommonJS) → строки SVG. Сцена 200 × 280 единиц, x вправо, y вниз. Правила стиля —
`docs/mockups/print/STYLE.md`. Стенды-проверки (листы для проверяющих) — в git, `kit/stands/*.cjs`:
`light.cjs` (материалы шаром, цилиндром и ящиком в 4 схемах света; среды), `ships.cjs`, `props.cjs`, `sky.cjs` (небо: луна, звёзды, солнце, закат). Рендер в PNG:
`node tools/card-art/kit-sheet.mjs tools/card-art/scenes/kit/stands/props.cjs --out report/print/kit --width 2000`
(`--only имя,имя` — отдельные листы, `--crop x,y,w,h` — увеличение в единицах листа).

```js
const K = require('../kit/index.cjs');
const light = { time: 'night', key: { type: 'moon', x: 146, y: 34, el: 24 }, haze: .35 };
module.exports = { name: '…', kind: 'deck', status: 'draft', cam: { x: 0, y: 0, w: 200 }, light,
  scene: u => {
    const L = K.makeLight(light, { horizon: 96 });
    const bg = K.sky(u, L, { horizon: 96 }) + K.sunMoon(u, L) + K.water(u, L, { horizon: 96, bottom: 152 }) + K.deck(u, L, { horizon: 96, top: 150 });
    const fg = K.castShadow(u, L, { x: 78, y: 206, w: 22, h: 26, horizon: 96 }) + K.contactShadow(u, 78, 206, 22, L) + K.shadeSphere(u, 78, 193, 13, L, 'iron');
    return [bg, fg];
  } };
```

Общее: `u` — суффикс сцены (первый аргумент везде). Каждый id — `k<имя><u>n<счётчик>`, не повторяется. Все
функции возвращают **одну строку** со своими `<defs>` внутри (кроме `mat` — она возвращает объект). Случайность —
только от `seed`. Соседним предметам давай разные `seed`.

**Порядок слоёв.** Тени (`castShadow`, multiply) и свет (`localGlow`, `sunMoon`, `fire`, `muzzleFlash`, screen)
смешиваются с тем, что нарисовано **раньше в той же группе**. Клади их прямо в слой сцены, не внутрь `<g>` с
`opacity`, `filter`, `clip-path` или `mask` — там смешивание отрезается от фона. Порядок: фон → опора (палуба) →
падающие и контактные тени → предметы → свет и дым поверх.

## Свет — `light.cjs`

### `makeLight(light, cam?)` → `L`

`light` — схема сцены (она же поле `light` файла сцены):

| Поле | Что это |
|---|---|
| `time` | `'night' \| 'day' \| 'dusk' \| 'fog'` — палитра неба, воды, тени (`PAL[time]`) |
| `key.type` | `'sun' \| 'moon'` — параллельный свет; `'point'` — фонарь, свеча, огонь |
| `key.az`, `key.el` | градусы. az: 0 — свет из глубины на зрителя (контровой), 90 — справа, 180 — из-за спины, 270 — слева; el — высота |
| `key.x`, `key.y` | место источника в картинке. Для солнца и луны можно дать `x, y` вместо `az` (и `el`) или наоборот — недостающее считается по камере. Для `point` — место лампы |
| `key.h`, `key.gy` | `point`: высота лампы над опорой, м; `gy` — y точки опоры под лампой (если не дан, считается из `h`) |
| `key.radius`, `key.z` | `point`: на этом расстоянии свет слабеет вдвое (130); доля света «на зрителя» (0,38) |
| `key.color`, `key.power` | цвет и сила (0..1) |
| `fill` | `{ color, power }` — небо, вода, отражённый свет: цвет собственных теней |
| `rim` | `{ az, color, power }` — контровой: тонкая светлая кромка у шаров и цилиндров |
| `locals[]` | `{ x, y, h, color, power, radius }` — фонари сцены: тёплый бок у форм внутри радиуса |
| `haze` | 0..1, плотность воздуха; `shadowTint` — свой цвет тени (необязательно) |

`cam` = `{ horizon: 108, cx: 100, f: 320, eye: 1.7 }` — горизонт (y), центр, фокус (ед.), высота глаза (м). По
ней строятся тени. **Передавай горизонт своей сцены.**

`L` содержит:
- `L.dx, L.dy, L.dz` — единичный вектор **на источник**: `dx, dy` в плоскости картинки (y вниз), `dz` — доля
  «на зрителя» (< 0 — контровой свет). `L.ux, L.uy` — то же направление единичным вектором в плоскости.
  Для точечного света это значение в центре картинки; для предмета бери `L.at(x, y)` → `{ dx, dy, dz, ux, uy, p, k }`
  (`k` — сколько силы дошло).
- цвета (hex): `L.keyColor` (= `lightColor`), `L.fillColor`, `L.shadowColor` (свет в тени), `L.reflexColor`,
  `L.rimColor`, `L.shadowTint` (цвет падающей тени: ночью сине-фиолетовый, у огня тёпло-коричневый, днём холодный),
  `L.shadowMul` (он же, поднятый до среднего тона — им тень умножает опору).
- `L.source` — `{ x, y }` источника в картинке или `null`; `L.front` — солнце или луна перед нами.
- `L.vanish(horizonY)` → `{ x, y, parallel, toward }` — точка схода теней на горизонте: под источником, если он
  перед нами (`toward`: тени идут к зрителю и расходятся); на противоположной стороне, если он за спиной;
  `parallel` — боковой свет, тени вдоль горизонта. Для `point` — `null` (тени идут от `L.keyBase(horizonY)`).
- `L.shadowAt(x, y, h, horizonY)` → `{ x, y, angle, len }` — конец тени столба высотой `h` (ед. картинки) с
  основанием в `(x, y)`; `angle`: 0 — вправо, 90 — вниз (к зрителю). Для своих теней и проверки `skel`.
- `L.tone(kind, I, x?, y?)` → hex: цвет материала при освещённости `I` (1 — лицом к свету, 0 — терминатор, −1 —
  от света). `L.ramp(kind, x?, y?)` → `{ lit, half, core, shadow, reflex, outline, spec }` — готовые тона для
  деталей, нарисованных руками (контур — `outline`).
- `L.ellipse(y, horizonY)` — сплюснутость круга, лежащего на опоре на высоте `y` (ry / rx): для днищ бочек и `ell`.
- `L.pal` — палитра времени: `sky[4]` (верх → горизонт), `sea[3]` (у горизонта → у зрителя), `cloudLit`,
  `cloudShade`, `fog`, `smoke`. `LIGHTS.pearl | revenge | endeavour | dutchman | sea` — готовые схемы колод.

### Материалы

`KINDS`: `iron, brass, oak, pine-deck, canvas, linen, leather, skin, rope, glass, water-wet, tar, paint-red,
paint-ochre, bone, coral`. Блик, рефлекс, просвет — по таблице `STYLE.md` (`MAT[kind]`).

**`mat(kind, L, { form, x1, y1, x2, y2, r, n, u })` → `{ defs, fill, id, ramp }`.** Градиент в `userSpaceOnUse`
по проекции света: свет → полутон → терминатор → тень → рефлекс. `defs` положи в сцену, `fill` — в `fill` или
`stroke` своей формы.
- `form: 'cyl'` — ось `(x1, y1)–(x2, y2)`, радиус `r`;
- `'sphere'` — центр `(x1, y1)`, радиус `r`;
- `'plane'` — противоположные углы грани и нормаль `n`: `'top' | 'front' | 'left' | 'right' | 'back' | 'bottom'`
  или `[x, y, z]` (x вправо, y вверх, z на зрителя);
- `'fold'` — складки ткани вдоль `(x1, y1)–(x2, y2)`, `r` — полуширина складки; градиент повторяется поперёк.
  Это ровные складки (рифы, занавес); неровные дорисуй тонами `ramp`. Парусина и лён против света светлеют.

```js
const hoop = K.mat('iron', L, { form: 'cyl', x1: 168, y1: 210, x2: 168, y2: 172, r: 15, u });
out += hoop.defs + `<path d="M153 202q15 7 30 0" stroke="${hoop.fill}" stroke-width="2.6" fill="none"/>`;
```

**`shadeCyl(u, x1, y1, x2, y2, r, L, kind, opts)`** — цилиндр от `(x1, y1)` до `(x2, y2)`: ствол, мачта, рука,
бочка. Блик — полоса вдоль оси на стороне света. `opts`: `r1, r2` — радиусы концов (сужение); `bulge` — пузо бочки
(0,14); `ell` — сплюснутость торцов (0 — вид сбоку; 0,2–0,35 — вид сверху; `cap: 'round'` — круглые концы);
`face: 1 | 2` — какой торец виден (1 — начало, 2 — конец); `outline: false | толщина`; `spec: false`;
`grain: false` (волокно дерева); `rim: false`; `seed`.

**`shadeSphere(u, x, y, r, L, kind, opts)`** — шар. Блик смещён к источнику на 0,3–0,4 r (при контровом свете
уходит на освещённый серп). `opts`: `outline`, `spec`, `rim`.

**`shadeBox(u, faces, L, kind, opts)`** — плоские грани: `faces = [{ pts: [[x, y], …], n, kind?, grain?: [dx, dy] |
false }]` в порядке отрисовки (дальние первыми). Тон грани — по нормали; у рёбер к свету — светлая потёртая линия.
**`boxFaces(x, y, w, h, ox, oy)`** → `[верх, бок, перед]` для ящика: перед — прямоугольник с левым нижним углом
`(x, y)`; задняя грань сдвинута на `(ox, −oy)` (`ox > 0` — виден правый бок).

### Тени и локальный свет

**`castShadow(u, L, { x, y, w, h, horizon, onto, wallY, opacity, d })`** — падающая тень стоящего предмета:
`(x, y)` — середина основания, `w` — ширина основания, `h` — высота (ед. картинки). Солнце и луна — к точке
схода, длина `h / tg(el)` с перспективой; `point` — веером от точки под лампой. Чёткая у основания, мягче к концу,
цвет `L.shadowMul` (multiply), не чёрная. `onto: 'water'` — бледнее; `wallY` — y подножия стены сзади (тень
поднимается по ней); `d` — глубина основания к ширине (1 — круглое). Основание должно быть ниже горизонта.

**`contactShadow(u, x, y, w, L, { ry, opacity })`** — тёмное «сиденье» под основанием `(x, y)` шириной `w`.

**`localGlow(u, loc, { squash, core })`** — тёплый круг света с затуханием: `loc = { x, y, color, power, radius }`
(элемент `locals` или точечный `key`). `squash` — сплюснутость (пятно на палубе 0,3); `core: false` — без ядра.

## Небо, вода, эффекты — `env.cjs`

| Функция | Что рисует |
|---|---|
| `sky(u, L, { horizon, stars, seed, top, avoid, clear })` | небо от `top` (0) до горизонта по `L.time` (зенит → горизонт; на закате ещё горящая полоса у горизонта), светлее вокруг источника; `stars`: число или `false` (ночью 70) — разной яркости и размера, редкие крупные с лучиками, гуще к зениту, у горизонта тускнеют, теплеют и гаснут; нет на луне и в её ореоле (`clear` — радиус, 19) и внутри `avoid` — список `{ x, y, w, h }` как у `cloud` |
| `sunMoon(u, L, { r, seed, phase, lit, rays })` | диск с ореолом в `L.source` — там же, где `makeLight` ставит источник света и теней. Луна: чёткий диск, к краю чуть темнее, свои пятна «морей» с тёмной серединой, при `r ≥ 9` мелкие кратеры; `phase` 0..1 — освещённая доля (1 — полная, по умолчанию): мягкий терминатор, в тени чуть пепельного света; `lit` — угол к освещённому краю (0 — вправо, 90 — вниз; 60). Солнце: белый диск, сияние и мягкие лучи разной длины над горизонтом (`rays: false` — без них; в тумане нет, на закате короче) |
| `cloud(u, L, { x, y, w, h, seed, far })` | облако одним объёмом: шары задают только контур (их объединение, край рвёт шум), свет и тень кладутся на всё объединение — швов между шарами нет; свет со стороны источника, мягкие светлые шапки на клубах к свету, мягкие складки между клубами, тень снизу, плоский низ; против света — тёмное тело и светлая кромка к источнику. `x` — середина, `y` — плоский низ. `far` 0..1 — бледнее, к тону горизонта, складки и кромка слабее |
| `cloudBank(u, L, { y, h, x0, x1, n, seed, far })` | ряд из `n` облаков с низом около `y` |
| `water(u, L, { horizon, bottom, swell, seed, glitter })` | море в перспективе до `bottom`: гребни мельче и чаще к горизонту, крупнее и контрастнее у зрителя; не рядами — у каждого гребня своя длина, высота, перекос и наклон, плавный шум в перспективе даёт пятна ряби и штиля (ветер); гребень — светлый серп с резким верхом и тающим низом над тёмной ложбиной; дорожка бликов под источником — рваная: ряды бликов чуть гуляют вбок, часть рядов слабее, длинный блик рвётся на два куска. `swell` 0..1; `glitter: false` или x дорожки |
| `foam(u, { x, y, w, seed, h, L })` | пена по линии касания с серединой `(x, y)`, шириной `w`, толщиной `h`: куски разной длины (то внахлёст, то с разрывом), у каждого бугристый верх на свету и ровнее низ, просветы моря внутри, рваный край; кружево — плоские штрихи пены на воде перед и за линией, цепочками |
| `reflection(u, svgBody, { y, h, L, opacity, stretch, seed })` | отражение `svgBody` строго вниз от ватерлинии `y` на глубину `h`: размыто, разорвано рябью, гаснет. Id внутри переименованы — то же тело рисуй и над водой |
| `splash(u, { x, y, w, h, seed, L, wind })` | всплеск на воде в `(x, y)`: полупрозрачное тело и рваная масса воды, свет со стороны источника, завесы воды кончаются не иглой, а сгустком, распадающимся на капли; капли вытянуты по полёту; край масс рваный (шум по краю ≤ 2,6 ед.); тёмное кольцо и пена у подножия. `seed % 3` — столб с короной, низкая корона струй вокруг горба с тонкой струёй, веер, снесённый ветром (`wind` — знак) |
| `fog(u, L, { y, h, density, seed })` | полоса тумана от `y` вниз на `h` |
| `smoke(u, L, { x, y, w, h, seed, wind, opacity, glow })` | дым от `(x, y)` вверх на `h`, ширина наверху `w`, `wind` −1..1: узкий ствол, клубы разной величины внахлёст (не бусы), верх сносится по ветру; один объём, как у облака: свет сверху и со стороны источника, тень под каждым клубом; редеет кверху (вуаль поверх непрозрачного силуэта — без швов); против света — тёмнее, светлая кромка. `glow: { color, power }` — подсветка огнём снизу |
| `fire(u, { x, y, w, h, seed, glow, wind, fuel, pool })` | огонь на `(x, y)`: языки S-образные, разной длины и наклона (`wind`); слои снизу вверх: копоть над языками → тёмно-красная кайма → рыжее тело → жёлтое ядро → белое сердце внизу со свечением; у каждого слоя цвет идёт от горячего основания к тающим кончикам; искры по размеру огня, свой свет (`glow: false` — без него), пятно на опоре (`pool: false`), `fuel: true` — горящие доски |
| `muzzleFlash(u, { x, y, dir, len, seed, smoke, glow })` | вспышка выстрела у дула `(x, y)` вдоль `dir` (градусы: 0 — вправо, 90 — вниз), длиной `len`; `seed % 3` — копьё, короткий широкий сноп, раздвоенное пламя с боковыми струями |
| `deck(u, L, { horizon, top, bottom, vx, seed, kind, plank, wet })` | палуба в перспективе от `top` до `bottom`: доски сходятся в `(vx, horizon)`; при `point` — пятно света под лампой; `wet` — полоса света под источником |

```js
const ship = hullSvg;                                         // свой рисунок корпуса над водой
bg += K.reflection(u, ship, { y: 120, h: 24, L }) + ship + K.foam(u, { x: 100, y: 120, w: 60, L, seed: 4 });
fg += K.muzzleFlash(u, { x: 142, y: 96, dir: -8, len: 28, seed: 2 })
   + K.localGlow(u, { x: 150, y: 124, color: '#ffc070', power: .5, radius: 30 }, { squash: .3, core: false }); // пятно на воде
```

## Корабли — `ship.cjs`

Четыре корабля игры и три нейтральных судна — одна параметрическая конструкция (корпус → пояса и бархоуты → ряды
портов с крышками → корма с галереей → бак → гальюн и бушприт → мачты из трёх колен с марсами → реи → паруса →
ванты с выбленками, штаги → бегучий такелаж → флаги). Корабли различаются **параметрами силуэта** (`SHIP_SPECS`,
по «таблице для художника» из `docs/mockups/print/ships-refs.md`). Вид — профиль, нос влево. Все точки считаются
в единицах сцены, поэтому свет, блики и кант остаются на стороне источника и при `flip`, и при `heel`.

**`ship(u, L, opts)`** → одна группа `<g>`. `opts`:

| Поле | Что это |
|---|---|
| `kind` | `'pearl' \| 'revenge' \| 'endeavour' \| 'dutch' \| 'merchant'` (флейт без портов) `\| 'brig'` (две мачты) `\| 'warship'` (нейтральный военный: фрегат или линейный корабль — тёмный корпус со светлой полосой, два ряда портов, прямой нос без гальюна, три мачты, целые светлые паруса, белые вымпелы, без цветов колод; для флотов вдали) |
| `x, y` | середина ватерлинии в единицах сцены (`y` — линия воды: ниже неё корпус обрезан) |
| `scale` | 1 — корпус по ватерлинии около 100 ед. («Жемчужина» и «Индевор» 104, «Голландец» 90, «Месть» 84, флейт 70, бриг 66) |
| `flip` | нос вправо |
| `heel` | градусы: наклон в плоскости картинки (плюс — нос вниз, мачты вперёд) — это дифферент, а не крен |
| `roll` | градусы, −20…+20: **крен** — поворот вокруг продольной оси на ватерлинии (плюс — на зрителя, палуба к нам; минус — от зрителя). Сочетается с `heel`: сначала крен, потом дифферент в плоскости картинки. `roll: 0` и без параметра — тот же SVG |
| `sails` | `'full'` \| `'reefed'` (нижние паруса и брамсели убраны, марсели зарифлены) \| `'furled'` (всё убрано, реи приспущены) |
| `detail` | `'near'` \| `'mid'` (без гвоздей, юферсов, риф-сезней, реже выбленки) \| `'far'` (без мелочей, контура и такелажа; тона уходят к небу у горизонта по `L.haze`) |
| `wake` | пена у форштевня и вдоль борта, кильватерный след за кормой |
| `reflect` | отражение строго под кораблём (`reflection`), из упрощённого тела |
| `lights` | свет в окнах кормы и в фонаре, отсвет на воде (у «Голландца» — бледно-зелёный); горит только ночью, в сумерках и в тумане, часть окон тёмная; днём (`L.time === 'day'`) стекло тёмное с бликом неба |
| `seed` | свой рисунок досок, прорех, заплат, выбленок (по умолчанию — от `kind`) |
| `wind` | `-1 \| 1` — знак ветра в сцене (как у `smoke`, `fire`, `splash`: плюс — вправо): куда летят флаги и вымпелы. По умолчанию — к носу, по ветру, который надувает паруса (`-1` без `flip`, `1` с `flip`); ветер в нос (`wind` против носа) — для корабля на якоре или с убранными парусами, кормовой флаг тогда летит за корму (`shipBox` с тем же `wind` это учитывает) |

Свет: борт — тона материала по высоте (завал бортов светлее сверху, подзор и днище в тени, округление носа и
раковины — по стороне света); мачты и реи — `shadeCyl`; паруса — выпуклые, свет со стороны источника, швы
полотнищ и рифы темнее. Контровой свет (`L.dz < −0,25` или `light.rim`): паруса светятся на просвет, сквозь них
темнеет мачта, по краям корпуса и парусов со стороны источника — светлый кант. Флаги летят к носу — по ветру,
который надувает паруса, или по `opts.wind`; дым в сцене — туда же: **`shipWind(opts)`** → `-1 | 1` — знак ветра
корабля, его передают в `smoke({ wind })`, `fire`, `splash`.

**Флаги и вымпелы** (`flagCloth` — общая функция рисования, ею рисуют и корабль, и `shipFlag`): полотнище не плоское —
2–3 бегущие складки, наклонённые (верх впереди), их глубина растёт от шкаторины к свободному краю, полотнище
сужается к нему и треплется; где складка отвёрнута от зрителя, полотнище сжато в ракурсе, и рисунок на нём (полосы
Компании, торговые, череп с костями) гнётся и сжимается вместе с ним. Свет по складкам: склон к источнику и гребень
светлее, впадина темнее (`L.at`, тот же источник, что у корпуса и парусов). Крепление: шкаторина — полоса
двойного полотна вдоль древка, фал от шкива к верхнему и от нижнего угла вниз, с клевантами на углах; флаг на
флагштоке с клотиком над топом грот-мачты, кормовой — на кормовом флагштоке, вымпел — на палочке у топа.
Длинный вымпел у грот-мачты — с раздвоенным хвостом, короткие — острые, рваные (`cond: 'torn'`, «Голландец») — с
хвостами разной длины. Вдали (`detail: 'far'`) — без шкаторины и фала, складки остаются.

**`shipFlag(u, L, opts)`** → `<g>` — один флаг или вымпел отдельно (тот же рисунок, что на корабле) для стендов и
крупных планов. `opts`: `x, y` — верх шкаторины в сцене, `scale`, `design`: `'jolly' | 'company' | 'merchant' |
'trade' | 'plain' | 'pennant'`, `w, h` — длина и высота полотнища (9,5 × 5,6; вымпел 22 × 2,2), `wind: -1 | 1`
(по умолчанию `-1` — влево), `color` — материал вымпела (`'ship-flag-red'`), `torn`, `fork` — раздвоенный хвост
вымпела, `staff` — длина флагштока под шкаториной (0 — без него), `detail`, `seed`. Стенд: `kit/stands/flags.cjs`
(лист `flags` — все виды крупно, ветер влево и вправо, день и ночь; лист `ships` — «Жемчужина» и «Индевор» целиком
с дымом по тому же ветру, флаги у топа и кормовой флаг крупно, `wind` против носа).

**Крен (`roll`).** У каждой точки корабля есть третья координата Z (поперёк, + к зрителю, 0 — диаметральная плоскость):
борт и всё на нём — на полуширине корпуса `b(X, H)` (из `SHIP_SPECS`: `beam` — ширина к длине по прототипу, завал
`tumble`, осадка `draft` и полнота днища `bilge`), мачты, реи, паруса, бушприт — на Z = 0, ванты — от русленей
(Z = ±(b + 0,9)) к марсу. Проекция: `H' = H·cos φ − Z·sin φ`, нормали света поворачиваются так же. Что видно:
φ > 0 — полоса палубы высотой 2·b·sin φ между ближним и дальним планширем (доски, решётчатые люки, пушки на лафетах
обоих бортов и порты в дальнем фальшборте, пяртнерсы мачт, кнехты, бухты), внутренняя сторона дальнего фальшборта
цветом `inner`; ближний борт ниже, вода у нижнего ряда портов, мокрая полоса, толстая пена вдоль борта, бурун у
форштевня с брызгами, длинный кильватер; мачты ниже в cos φ, их основания на палубе (видны с ~11°), дальние ванты
расходятся с ближними. φ < 0 — палубы нет, ближний борт поднят: днище под старой ватерлинией (`bottom`: обрастание,
медная обшивка у «Индевора», смола у флейта), водоросли, мокрый блеск, полоса налёта. При любом крене паруса туже,
флаги и вымпелы вытянуты. Отражение и силуэт строятся через тот же `roll`. Стенды: листы `roll-<kind>` и
`roll-user` в `kit/stands/ships.cjs`. **`shipGeom(kind, opts)`** — спроецированные точки (планширь, верх мачт) для проверок.

**`shipSilhouette(kind, opts)`** — тот же корабль одним тоном (`opts.color`, по умолчанию `#1b1d22`), без света и
фона: порты и прорехи парусов — сквозные. `opts`: `x, y, scale, flip, heel, roll, sails, seed, u`. Для слепой проверки
узнаваемости (п. 20 ревью). **`shipBox(kind, { x, y, scale, flip, wind })`** → `{ x0, x1, top, y, w, h }` — габарит для
компоновки. **`SHIP_SPECS`** — таблица параметров (длина, борт, седловатость, ярусы кормы, ряды портов, мачты; для крена —
`beam`, `draft`, `bilge`, `inner`, `deckK`, `bottom`). Порты идут ровным шагом вдоль седловатости своей палубы, ряды
соседних палуб сдвинуты на полшага (шахматный порядок); открытая крышка изнутри красная. «Индевор» — «шахматка Нельсона»: каждый ряд портов (и пушки открытой палубы) в своей полосе
жёлтой охры, между полосами чёрные шириной около 0,8 полосы, низ чёрный. Крупно оба больших корабля — стенд
`kit/stands/ships-big.cjs` (листы `big-endeavour`, `big-dutch`: свет своей колоды и день, силуэт, `mid`). Тёмного контура-обводки
у форм нет (корпус, паруса, корма, марсы, флаги): границы задаёт тон и свет; силуэт от этого не меняется.

## Предметы — `props.cjs`

Вещи сцены, собранные так, как они устроены, и освещённые светом сцены `L`. Общее для всех: `name(u, L, opts)` →
одна строка SVG. `opts`: `x, y` — точка опоры (середина основания), `s` — масштаб (1 — размеры ниже), `rot` —
градусы по часовой, `flip` — зеркально, `seed`, `ell` — своя сплюснутость эллипсов (по умолчанию `L.ellipse(y)`).
Вся геометрия считается в единицах картинки, поэтому свет и блики остаются светом сцены и при `rot`, и при `flip`.
Предмет возвращается **без падающей тени** (положи `castShadow` с размерами из таблицы × `s`), но с контактной
тенью у основания (`contact: false` — без неё). Вещи с размером по высоте ставь по `y` сверху вниз: дальние первыми.

## Люди — `print/lib/people.cjs`

Фигура целиком — **`figure(u, o)`**: скелет 7,5 головы (плечи ≈ 2 головы, локоть на талии, кисть до середины бедра)
в позе, повёрнут и спроецирован; тело — ткань по трубкам с перекрытием суставов, торс — кольцами, голова — `head34`.
Поза пишется для фигуры лицом вправо; `dir: -1` зеркалит рисунок (свет не зеркалится). `R` — ближняя сторона, `L` — дальняя.
- `at: [x, y]` — пол под тазом (нижняя подошва стоит на `y`), `h` — рост стоя (120), `L` — свет сцены (обязателен).
- `pose`: `'stand'` (вес на ближней ноге, рука на бедре) | `'walk'` | `'haul'` (канат) | `'aim'` (пистолет; дальняя рука
  низко — сабля) | `'saber'` (к бою) | `'sit'` (за столом) | `'helm'` (у штурвала) или свой объект как в `FIG_POSES`.
- `adjust` — правки позы: `{ arms: { R: { upper: [сгиб, отвод], fore: [..] } }, legs: { L: { thigh, shin, foot } }, torso:
  [крен, наклон, поворот] }` (градусы в теле до поворота); рука целью — `{ to: [x, y, z], pole }`; `turn` (0 к нам … 1 профиль).
- `reach: { R: [x, y], L: [x, y] }` — точки картинки для запястий (IK; так кисти ставят на рукояти штурвала, канат, стол).
- `dress: { shirt, vest, coat, coatLen: 'hip' | 'knee', trousers, boots, boot: 'high' | 'shoe' | 'bare', belt, sash,
  kerchief, sleeves: 'rolled' }` — цвета (тон по свету сцены) или готовые рампы; `false` — нет.
- `head` — опции `head34` (волосы, борода, взгляд…; `turn`, `nod` прибавляются к позе); `hat: { color, trim }` — треуголка;
  `skin` (рампа; по умолчанию `L.ramp('skin')` с мягким терминатором), `dim`, `rim` (`false` — без контрового), `seed`.
- Кисти: `hand(u, info)` → `{ back, front }` вместо `hand3`; `info = { side, at, a, s, m, pose, tone, light, L, sw }`;
  `hands: { R: 'wrap' }` — позы кистей; `handsSeparate: true` — кисти не в `svg`: рисуй `back` + предмет + `front`.
- Тени: контактные под подошвами; с `horizon` — и падающая. `shadow: false` — без них.
- Возвращает `{ svg, layers: { shadow, back, legs, body, head, front }, hands, wrist: { R, L } ({ at, a, depth }),
  joints: { R, L } (shoulder, elbow, wrist, hip, knee, ankle, toe, heel), head (результат head34), seat (для 'sit'), top, Hh }`.
  Стол, сундук, штурвал кладут между `layers.head` и `layers.front`.

Мелкое: `cloth({ tension: true })` — складки только на сгибах, по глубине сгиба (по умолчанию прежние); `head34` — слабая
складка нос–рот (`folds: false` — без неё), `jawW` (уже челюсть), `tailApart` (косичка отдельно — за спину). Стенд —
`stands/people.cjs`.

## Интерьеры — `interior.cjs`

Комната в 2,5D — пол, стены, потолок с балками к одной точке схода, всё в метрах (X вправо, Y вверх от пола, Z вглубь), грани тонируются по нормали к источнику, дальше — темнее. Стенд: `kit/stands/interior.cjs`.

```js
const s = K.interior.scheme('cabin', { mood: 'lamp' });       // { light, cam, vp, lamps, geom }; mood: 'lamp' (ночь, свой фонарь/очаг — ключ) | 'window' (день из окон, в трюме — из люка) | у таверны ещё 'candles'
const L = K.makeLight(s.light, s.cam);                       // cam = { horizon: vp[1], cx: vp[0], f, eye } — тот же, что у комнаты (иначе тени не лягут)
bg += K.interior(u, L, { kind: 'cabin', mood: s.mood, off: ['table'], gloom: false });   // 'cabin' | 'gundeck' | 'hold' | 'tavern'
const g = K.interior.geom({ kind: 'cabin' }), q = g.at(.3, 3.1, .78);  // своя вещь на столе: { x, y, upm } (ед. картинки на метр)
fg += K.barrel(u, L, { x: q.x, y: q.y, s: q.upm * .9 / 30 }) + K.interior.gloom(u, L);      // gloom — тёмный низ под стеклом и края, кладётся последним
```
Опции: `vp` [x, y], `f`, `eye` (м), `room: { xl, xr, h, d }` (м) или `back: { x0, x1, top, bot }` — задняя стена в картинке; `detail: 'near' | 'mid'`; `seed`;
`props: false` — пустая комната; `off: [имена]` / `items: { имя: false }` — убрать часть (каюта: windows, panels, bench, shelves, beams, table, chart, chest, lamp;
палуба: ports, guns, shot, mast, ropes, beams, lamp; трюм: water, ribs, platform, hatch, ladder, barrels, crates, rope, lamp; таверна: hearth, window, shelves,
counter, candles, barrels, beams); `win: { az, el, color, power } | false` — свет из окон (пятна переплёта на полу и столе, лучи в воздухе); `outside: 'night' | 'day'`.
Свет — из `L`: точечный ключ — фонарь (`lantern.local`), очаг, люк; солнце — через окна. Новые материалы в `MAT`: `oak-old`, `pine-old`, `stone`, `plaster`, `soot`, `bilge`.
Основная вещь сцены — выше линии стекла (58 %, y 162): по умолчанию стол, пушки, стойка и люк стоят выше неё.
