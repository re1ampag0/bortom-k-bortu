# Картинки карт: исходники

Здесь исходники всех 81 картинки карт. Каждая картинка — векторная SVG-сцена 200 × 120, которую собирает код
в `scenes/`. Из этих сцен получены WebP в `src/ui/art/cards/` (600 × 360, рамка цвета типа нарисована внутри).
Сцены нарисованы для макетов от 26.10.2026: это свои рисунки плюс готовые SVG-детали игры (иконки меню, пушка
и ядра палубы, корабли меню, особенности из окна корабля). Кадров из фильмов нет.

Сцены векторные, поэтому картинку можно получить в любом размере без потери резкости, например для печати.

## Как получить картинки

```
node tools/card-art/export.mjs --out <папка> [--scale 3] [--no-frame] [--only "Ядра,Анжелика"] [--svg]
```

- `--scale 3` — 600 × 360 (по умолчанию); `--scale 10` — 2000 × 1200, для печати.
- `--no-frame` — без рамки цвета типа и уголков (для печати, где рамку рисует сама карта).
- `--only` — только перечисленные карты (имена как в `data/game-data.json`).
- `--svg` — заодно сохранить каждую сцену отдельным `.svg`.
- `--compare <папка>` — рядом с PNG кладёт `<slug>-compare.jpg`: «было» из папки прошлого экспорта | «стало», под ними миниатюры 240 × 144.
- `--webp` — файлы для игры: `<slug>.webp` 1200 × 720 (окно карты, резко на экранах с плотностью 2–3×) и `thumb/<slug>.webp` 240 × 144 на цвете бумаги карты.

### Портретные картинки печатной карты

```
node tools/card-art/export.mjs --portrait --out report/portrait [--scale 3] [--only "Ядра,Анжелика"] [--svg]
node tools/card-art/export.mjs --portrait --sheet --out report/portrait
node tools/card-art/export.mjs --portrait --only "Указ о казнях" --skel --out report/portrait
node tools/card-art/export.mjs --portrait --only "Указ о казнях" --scale 6 --guides --grid --out report/portrait/x6
```

- `--portrait` — картинки печатной карты из `scenes/portrait.cjs`: `<slug>.png` 200 × 280 × `--scale` (3 → 600 × 840,
  6 → 1200 × 1680) и, без `--only`, `manifest.json`. Если у какой-то карты нет портретной сцены, команда
  перечисляет такие карты и завершается с ошибкой.
- `--sheet` — вдобавок листы-обзоры `sheet-<колода>-<n>.png`: по 6 карт, каждая — макет настоящей карты В-2
  300 × 420 px поверх картинки: медаль типа, цена, стеклянная панель с текстом карты из `data/game-data.json`
  (под ней размытая и затемнённая картинка), полоса колоды. Только для проверки: видно, что закрывает стекло.
  `--sheet` ещё пишет `glass.json`: `{ имя: верх стекла в % высоты карты }` (с `--only` дописывает к прежнему файлу).
- `--skel` — вместо сцены скелет `SKEL[имя]` из файла колоды (`scenes/portrait-<колода>.cjs`, экспорт рядом с
  `SCENES`) в `skel/<slug>.png`: исходная горизонтальная картинка подложкой (`orig: {k, tx, ty}`), горизонт,
  прямоугольники предметов с id и опорой. Печатает предупреждения: два прямоугольника пересекаются, а опора ни одного
  не называет другой (`on X`, `behind X`, `held by X`); высота предмета на `ground` расходится с
  h = H · (y_осн − y_гор) / E больше чем на 15 %; основание на земле выше горизонта; предмет в углу 45 × 45 сверху
  или ближе 10 к краю (если это фон или масса под стеклом — `{ edge: 1 }` последним элементом). Формат предмета:
  `[id, x левого края, y основания, w, h, опора, высота в м (для ground), {edge}]`.
- `--guides` — `guides/<slug>.png`: картинка с линиями y 126 (45 %), y 140 (50 %), линией стекла этой карты, углами
  45 × 45, полями 10 и горизонтом из `SKEL`.
- `--grid` — `grid/<slug>-r<1–4>c<1–3>-x<…>-y<…>.png`: 12 крупных клеток картинки (3 × 4, 66,7 × 70 единиц,
  нахлёст 8) при `deviceScaleFactor` 10 — для поиска висящего, разрывов и наложений.
- Если Chromium не совпадает с версией Playwright проекта, путь к нему — в переменной `CHROMIUM_PATH`
  (в облачном контейнере: `CHROMIUM_PATH=/opt/pw-browsers/chromium`).

Нужны `npm ci` (Playwright с Chromium и шрифты `@fontsource`). Результат — PNG (или WebP) и, если выгружены
все карты (без `--only`), `manifest.json` (имя карты → файл, тип, колоды).

PNG в репо не коммитить. Обновить картинку в игре после правки сцены:

```
npm run card-art -- --webp --only "Ядра" --out src/ui/art/cards
```

Как дорабатывать картинки — `docs/tasks/card-art-polish.md`.

## Что где

| Файл | Что это |
|---|---|
| `scenes/art.cjs` | Общие материалы (железо, дуб, латунь), детали игры из репо, базовые сцены |
| `scenes/art3.cjs`, `scenes/bg4.cjs` | Фоны (море, каюта, трюм, причал), облака, волны, пальмы, фонари |
| `scenes/helpers4.cjs`, `scenes/pieces4.cjs` | Корабли на воде, тени, отдельные предметы (компас, щупальце, брандер и т. д.) |
| `scenes/specs3.cjs` | Сцена для каждой карты по её имени |
| `scenes/pic3.cjs` | `picture3(имя, цвет рамки)` — готовая картинка: сцена, виньетка, рамка |
| `scenes/portrait.cjs` | Вертикальные сцены 200×280 для печатных карт (разметка В-2 — `docs/tasks/card-art-portrait.md`); `portrait(имя, {layer: 'fg'})` — только передний план; `backArt('pearl')` — картинка рубашки колоды |
| `export.mjs` | Рендер всех картинок в PNG |

Проверка переноса (29.10.2026): все 81 картинка при `--scale 3` совпадают с WebP в игре, средняя разница
пикселей 2–3 из 255 (это сжатие WebP).
