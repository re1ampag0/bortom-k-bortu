# Картинки карт: исходники

Здесь исходники всех 81 картинки карт. Каждая картинка — векторная SVG-сцена 200 × 120, которую собирает код
в `scenes/`. Из этих сцен получены WebP в `src/ui/art/cards/` (600 × 360, рамка цвета типа нарисована внутри).
Сцены нарисованы для макетов от 26.10.2026: это свои рисунки плюс готовые SVG-детали игры (иконки меню, пушка
и ядра палубы, корабли меню, особенности из окна корабля). Кадров из фильмов нет.

Сцены векторные, поэтому картинку можно получить в любом размере без потери резкости, например для печати.

## Как получить картинки

```
node tools/card-art/export.mjs --out <папка> [--scale 3] [--no-frame] [--only "Ядра,Анжелика"] [--svg]
```

- `--scale 3` — 600 × 360 (по умолчанию); `--scale 10` — 2000 × 1200, для печати.
- `--no-frame` — без рамки цвета типа и уголков (для печати, где рамку рисует сама карта).
- `--only` — только перечисленные карты (имена как в `data/game-data.json`).
- `--svg` — заодно сохранить каждую сцену отдельным `.svg`.
- `--compare <папка>` — рядом с PNG кладёт `<slug>-compare.jpg`: «было» из папки прошлого экспорта | «стало», под ними миниатюры 240 × 144.
- `--webp` — файлы для игры: `<slug>.webp` 1200 × 720 (окно карты, резко на экранах с плотностью 2–3×) и `thumb/<slug>.webp` 240 × 144 на цвете бумаги карты.

Нужны `npm ci` (Playwright с Chromium и шрифты `@fontsource`). Результат — PNG (или WebP) и, если выгружены
все карты (без `--only`), `manifest.json` (имя карты → файл, тип, колоды).

PNG в репо не коммитить. Обновить картинку в игре после правки сцены:

```
npm run card-art -- --webp --only "Ядра" --out src/ui/art/cards
```

Как дорабатывать картинки — `docs/tasks/card-art-polish.md`.

## Что где

| Файл | Что это |
|---|---|
| `scenes/art.cjs` | Общие материалы (железо, дуб, латунь), детали игры из репо, базовые сцены |
| `scenes/art3.cjs`, `scenes/bg4.cjs` | Фоны (море, каюта, трюм, причал), облака, волны, пальмы, фонари |
| `scenes/helpers4.cjs`, `scenes/pieces4.cjs` | Корабли на воде, тени, отдельные предметы (компас, щупальце, брандер и т. д.) |
| `scenes/specs3.cjs` | Сцена для каждой карты по её имени |
| `scenes/pic3.cjs` | `picture3(имя, цвет рамки)` — готовая картинка: сцена, виньетка, рамка |
| `scenes/portrait.cjs` | Вертикальные сцены 200×280 для печатных карт (пока 6 карт); `portrait(имя, {layer: 'fg'})` — только передний план для эффекта «выход за рамку» |
| `export.mjs` | Рендер всех картинок в PNG |

Проверка переноса (29.10.2026): все 81 картинка при `--scale 3` совпадают с WebP в игре, средняя разница
пикселей 2–3 из 255 (это сжатие WebP).
