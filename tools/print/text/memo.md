# Памятка

> Бортом к борту · одна на корабль

## РАУНД

1\. Море (открыть карту) · 2. Ход Пиратов · 3. Ход Компании

::: add
Откройте верхнюю карту моря, прошлую — в сброс. «Сразу» срабатывает один раз — здесь, до Трюма Пиратов. «Весь раунд» — до следующей карты моря.
:::

## ХОД КОМАНДЫ

1. **Трюм:** +3 Пороха (не больше 8). Затем жгут Пожары.

::: add
- В самый первый ход Пиратов — только +2. Больше 8 — лишний сгорает.
- Пожары: 1 урон по Корпусу за каждый. Тушить — потом, в любой момент своего хода.
- Затем по порядку: «Голландец» всплывает, «Девятый вал», «Мальстрём».
:::

2. **Добор:** до 5 карт (Планы — в руке).

::: add
- Лимит карт — Команда в этот момент (+1 «Флот на горизонте»). Упала Команда посреди хода — лимит не уменьшается.
:::

3. **Действия** (союзники одновременно): **карт — не больше Команды**; 1 Залп на корабль.
4. **«Ход окончен».**

::: add
- Смахните маркеры хода, снимите эффекты «до конца хода». Ходит другая команда.
:::

## СВОБОДНЫЕ ДЕЙСТВИЯ

- Продать карту: +1 Порох, раз в ход
- Передать союзнику 1 карту, раз в ход
- Перестроение: 1 Порох, раз в ход (пока «Жемчужина» на плаву — 0)
- Потушить Пожар: сбросить 1 карту

::: add
Перестроение нельзя, если у одного из кораблей Паруса 0.
:::

## ЗАЛП

**1 Порох** · **урон = Пушки** · по диагонали −1 · совместный залп +1 (раз в ход) · без Заряда бьёт по Корпусу · 1 Заряд на Залп

::: add
По порядку: Порох, цель (напротив или по диагонали), Заряд, Реакции противника, урон. Пушки 0 — Залп невозможен.
:::

---

## ХОД ПРОТИВНИКА

Реакций — не больше Парусов. Играйте после объявления Залпа или карты, до урона. Реакции за Порох оплачиваются из вашего Трюма.

::: add
- Порох на Реакции оставьте заранее — в чужой ход не продать.
- Паруса считаются в эту минуту: упали Паруса — меньше Реакций. Сверх Парусов: Реакция из Плана «Жемчужины» и 1 Реакция капитана утонувшего корабля.
- Исключение — карты со словами «после Залпа».
:::

::: add ЦЕНА
{coin} Монета — Порох из Трюма. {flask} Склянка — Души «Голландца». Нет значка — бесплатно.
:::

::: add ПОЖАРЫ
Не больше 3 на корабле. В начале хода своей команды — 1 урон по Корпусу за каждый Пожар. Потушить: сбросить 1 карту — снять 1 Пожар, сколько угодно раз, в любой момент своего хода. «Голландец», уходя под воду, тушит все свои Пожары.
:::

::: add «ЭТО НЕ ЗАЛП»
Не действуют диагональ, совместный залп и Реакции, которые меняют Залп, а также «Буря», «Ясное небо», «Чёрная метка», «Поднять флаги!», «Водоворот». Реакции «на Залп или карту» играть можно.
:::

## УРОН

Шкала на минимуме — остаток в Корпус. Команда не ниже 1. Корпус 0 — корабль тонет.

::: add
Ремонт — вверх, но не выше стартовой клетки.
:::

## КОРАБЛЬ ПОТОПЛЕН

Капитан на борту союзника: 1 карта в свой ход и 1 Реакция в ход противника. Легенда и особенности утонувшего корабля уходят.

::: add
Переверните его планшет. Рука и колода остаются у капитана, добор как обычно. Его Заряд к Залпу союзника — это и есть его 1 карта.
:::

::: add ЧУЖАЯ КАРТА
Украденная карта — ваши лимиты и ваш Порох, потом в сброс владельца.
:::

::: add КОЛОДА
Сыгранная карта — в сброс владельца. Карта долгого эффекта лежит у планшета цели (командная — на Схеме боя) до конца срока, потом — в сброс владельца. Колода кончилась — перемешайте сброс в новую колоду.
:::

::: add ХОД ОКОНЧЕН
Смахните маркеры хода, снимите эффекты «до конца хода».
:::

::: add ПЕРВАЯ ПАРТИЯ
Без Колоды моря и Легенд, Компания стартует с 3 Порохами.
:::
